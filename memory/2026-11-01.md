## 🔧 18:45–19:10 修复：skill-collection-review 超时链（根因+实证）

### 根因定位（三层超时，逐层收敛）
1. **cron `--timeout-seconds` 对 `agentTurn` 任务无效** —— CLI 直接拒绝：`--timeout-seconds is not supported for agentTurn jobs.`（不是配置错误，是该版本设计）
2. **真正卡死点是 provider idle watchdog = 120s** —— 日志实录：
   `LLM idle timeout (120s): no response from model` → `Profile minimax:cn idle timeout (model silent). No further authorized account for this provider`
   → 官方提示：`increase models.providers.<id>.timeoutSeconds`
3. **`agents.defaults.timeoutSeconds` 只管整轮 run 管不到 provider** —— 文档明确：provider timeout 受更低的上限约束，但**可以单独调 provider**。之前设的 1800 完全没生效在 120s 这一层。

### 生效配置（已备份 `~/.openclaw/openclaw.json.bak-20261031-1850`）
- `models.providers.minimax.timeoutSeconds`: **120s(隐式) → 600**
- `agents.defaults.timeoutSeconds`: **1800 → 3000**（给整轮 run 留足余量）
- 走 `openclaw config patch --file`（JSON5），**热重载生效，无需重启**；重启后 `reload failed` 计数仍为 0
- 实证：日志已从 `timeoutMs=undefined`/120s 变为 `timeoutMs=600000`

### 复核结果
- **zhanling**：✅ ok，313770ms（5.2 分钟）—— 从 error(1030468ms) 翻盘

### 🔑 关键教训

## 19:28 修复：provider catalog refresh failed（agent 数据库归属错配）

### 根因（源码级定位，非猜测）
`dist/sqlite-Cp6HSWY4.mjs:378` `inferAgentIdFromDir()` 的推导规则：
```js
if (path.basename(dir) === "agent") return path.basename(path.dirname(dir));
return `custom-${sha256(path).slice(0,12)}`;
```
而 `dist/openclaw-agent-db-schema-read-BtiXH6Vp.mjs:23` 校验 `schema_meta.agentId` 必须与推导值一致，否则抛
`OpenClaw agent database ... belongs to agent X; requested agent Y`。

**触发条件**：`agents.entries.<id>.agentDir` 被显式配置为**非约定路径**时，
`resolveEffectiveAgentDir()` 直接返回配置值（`agent-scope-config-D2MQzbc-.mjs:436`），
推导规则退化为 hash → 必然与真实 agent id 不符。

哈希验证（sha256 前 12 位，完全吻合）：
| agentDir | 推导 id | 实际 agent id |
|---|---|---|
| `agents/agent-memory` | `custom-04e7675caf51` | `memory-agent` ❌ |
| `agents/agent-frontend` | `custom-a19352716d67` | `frontend-dev` ❌ |
| `agents/main/agent` | `main` | `main` ✅（末段名为 agent，走父目录名） |

### 修复
4 个 agent 的 `agentDir` 指向**遗留目录**，而**活库在约定路径** `agents/<id>/agent/`：
| agent | 旧 agentDir（遗留） | 活库位置 | 库大小 |
|---|---|---|---|
| memory-agent | `agents/agent-memory` | `agents/memory-agent/agent/` | 50M |
| feishu-agent | `agents/agent-feishu` | `agents/feishu-agent/agent/` | 20M |
| tools-agent | `agents/agent-tools` | `agents/tools-agent/agent/` | 18M |

**动作**：备份 `~/.openclaw/openclaw.json.bak-20261101-1925` → 逐一 `openclaw config unset agents.entries.<id>.agentDir`
（4 次 unset 合并热重载，未重启 Gateway）→ 回落 OpenClaw 默认约定路径 `agents/<id>/agent`。
