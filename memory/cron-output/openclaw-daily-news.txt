1️⃣ 【v2026.10.6 补丁发布：专注安装、升级与启动稳定性】
10 月 23 日发布的 2026.10.6 是一个不含新功能的纯维护版本，重点修复全新安装、更新器可靠性、Gateway 启动、Windows 安装流程、Discord 指令回归、iPhone Talk 崩溃等问题，并加入了"可重放"的安全会话恢复机制——被中断的升级可以在 Windows/macOS/Linux 上安全续跑。官方建议各团队在下一个维护窗口安排更新。

2️⃣ 【v2026.10.5：侧边栏重构 + Skill Workshop 2.0 上线】
10 月 19 日发布的 10.5 是近期功能含量最高的一版：侧边栏新增 Subagents 与 Processes 面板，可以直接在父会话旁查看已派发的子任务和最近命令输出，支持定点 Stop 停止；完成的命令默认折叠、运行中的保持可见。同时 Skill Workshop 2.0 带来"版本留痕 + Undo"，最多保存 10 个版本，可对比改动、回滚旧版、归档后再恢复，新会话会使用更新后的技能。官方在 10.5 中合并了 2,250 个 PR、637 位贡献者。

3️⃣ 【公开会话链接：无需登录即可阅读，但也会暴露后续消息】
10.5 改进了会话分享：已发布的对话现在直接在正常的聊天地址打开，任何拿到链接的人都能读取记录，登录用户沿用原有权限。但官方在发布说明里特别强调风险边界——链接会暴露"现有及未来的"用户消息与最终回复，脱敏只是尽力而为，关闭分享也无法追回别人已经保存的副本。

4️⃣ 【OpenClaw Enterprise (OCE) 开源免费，落地企业级 Agent 控制平面】
9 月 29 日 OpenClaw 基金会宣布开源 OpenClaw Enterprise（OCE）：一个 MIT 协议、厂商中立、面向敏感环境的"持久化 Agent 管理平台"，前身是 OpenAI 内部项目，捐给基金会后由 Red Hat 和 NVIDIA 共同参与开发。它是独立仓库 openclaw/openclaw-enterprise，不 fork 运行时、不锁功能，提供多租户、可信/不可信工作负载硬边界、沙箱、基于 LLM 的复核、细粒度权限与全生命周期审计。OpenAI 与 Red Hat 已在内部试点运行。

5️⃣ 【微软 Autopilot 建立在 OpenClaw 之上，Scout 走的是"Agent 治理"路线】
9 月 25 日微软把 Copilot 重构为 Home / Code / Autopilot 三块，其中 Autopilot 直接基于 OpenClaw 构建；更早的 Build 2026 上微软还发布了桌面自主 Agent "Scout"。治理上每个 Autopilot 拥有独立的 Entra 身份、按任务限定权限，并由 Purview 策略实时拦截写操作。与之对照的是 OpenClaw 自己的"迟到但免费"路线——两者回答的是同一个问题：在企业里跑常驻 Agent 需要什么。

🧠 【豆浆学习笔记】

📌 版本落后提示
本地跑的是 2026.9.5，官方已到 2026.10.6，中间差了 9 个版本。9.5 → 9.7 那一段是"原子更新 + 备份校验 + 自动回滚"，10.x 又补了 Skill Workshop 2.0、子任务面板、公开会话链接。建议王抽一个维护窗口升级（务必用 `bash ~/.scripts/safe-gateway-restart.sh` 走安全重启，配置变更前先备份）。

💡 可直接落地的三件事
1️⃣ **Skill Workshop 2.0 的版本留痕** — 我们的工作流技能（比如飞书多渠道同步规则、派发标准格式）现在改错了只能手改文件回滚。10.5 之后可以走 Workshop 提案 → 审核 → 应用的正规流程，Undo 和 10 个版本存档相当于给技能加了 Git 保险。这条对我们的"铁律：主Agent不自己写代码"是天然配套——技能变更从此有可审计的评审轨迹。
2️⃣ **侧边栏 Subagents / Processes 面板** — 派发子Agent后能直接在会话旁看到运行状态和命令输出，配合定点 Stop，不用再靠我口头汇报"还在跑"。对多项目跟进的场景，透明度直接提升。
3️⃣ **公开会话链接要谨慎** — 一键把飞书里的对话变成免登录可读链接，虽然方便分享给王，但在公司环境里属于敏感信息外泄路径。我们的招投标内容、内部日志不适合走这个功能；如需汇报，建议改成"导出文档发飞书"，而不是公开链接。

⚠️ 风险与红线
• **自动学习有成本和隐私代价**：Skill 的 background learning 会把对话和工具内容发给当前配置的模型供应商（我们现在走 MiniMax），可能产生额外费用。可以设为 Off，但 `/learn` 手动触发仍可用——建议保持现状前先评估。
• **公开链接的"未来消息"陷阱**：不是快照而是持续暴露，关掉也追不回已保存副本，涉密内容一律不用。
• **722 条安全通告的数字要打问号**：不同来源统计口径不一，别被单一数字吓到或麻痹。真正该做的是保持版本跟进 + `openclaw doctor` 体检。

🔍 值得持续跟踪
• OCE（OpenClaw Enterprise）开源控制平面——多租户 + 硬安全边界 + 审计，这套思路正是"公司里跑多个常驻 Agent"该有的样子。招投标代理业务涉及多个项目、多个子系统交叉建设，将来若要横向铺开 Agent，OCE 的治理模型值得先读懂。
• 微软 Autopilot + Entra 身份 + Purview 策略，说明大厂 Agent 治理已经定型。我们不需要自建，但要知道边界在哪——尤其公司若采购 M365，Agent 365 的治理平面（$15/用户/月）可能会与我们的飞书工作流产生分工。
• 9.7 引入的"可重放会话恢复"和 10.6 的"升级可续跑"，对长会话 + 频繁升级的场景是刚需，值得在升级窗口实测一次。
