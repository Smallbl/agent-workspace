──────────────────────────────

是否有重大变化: 有，但性质为“安全/可靠性补丁”，无新功能
- 2026.10.7 起要求 Node >= 24.22.1 (<25) 或 >= 26.12.1 (>=26)，起因 2026 年 10 月 Node.js 安全公告中被吊销证书密钥（eMudhra）影响的 TLS 链。
- 2026.10.8 / 2026.10.9 均为安全发布：fast-uri 4.2.3、nodemailer 10.1.4 (IMAP 发件人伪造)、MSAL Node 7.1.1 (Teams)、A2UI/Discord 的 Zod 遍历边界；凭据脱敏（Google OAuth client secret、MCP CLI 检视、浏览器配对凭据不再进进程参数）。
- 2026.10.9 亮点：升级失败后可恢复（不再升级完就停服）、SQLite agent 库恢复、Git 回滚加固、Gateway 恢复路径强化。官方说明为 focused reliability fixes only，无新功能。
- 2026.10.10-beta.3/4/5（未转正）：Windows 启动可靠性、升级后 agent store 恢复、eMudhra 信任链修复、webhook/定时脚本作用域修正。

已知问题（2026.10.9，第三方 ClawStat.us 2026-10-31 评估 + GitHub issue 核对）:
- 5 个已确认的阻塞级 issue 未在 10.9 中修复: #187911、#187309、#188165、#187383、#187900
  · #187309 (critical): 活跃租约关闭后 per-agent SQLite WAL/SHM 身份不匹配（10.8 起出现）
  · #188165 (critical): 并发托管工作区编辑后 guest 任务无法恢复
  · #188424 (high): systemd user service 下 Gateway 拒绝自身 PID（Ubuntu VM）
  · #188647 (high): 模型 fallback 可能在派发备份模型前静默结束
  · #188218 (high): 已完成子结果在挂起为 permanent_failure 后每轮重复投递
- 历史回归: 2026.10.5 -> 2026.10.6 出现 Codex app-server 执行预算超时回归 (#181619)。
- ClawStat 建议“今日最佳运行版本”为 2026.10.7（已在野 7 天，已知问题少且无广泛影响）；10.9 发布仅 2 天，过新未沉淀。

⚠️ 阻塞项（本机）: 无法直接升级
- 本机 Node: v26.7.0。2026.10.7 及以上均要求 Node 24.22.1+ 或 26.12.1+。
- `openclaw update --dry-run --tag latest` 实测输出:
  "Would refuse update: openclaw@2026.10.9 requires Node >=24.22.1 <25 || >=26.12.1; selected runtime is Node 26.7.0."
- 恢复路径（官方给出）: 先用系统包管理器安装并切换 Node 24.22.1，然后执行
  node /opt/homebrew/lib/node_modules/openclaw/openclaw.mjs update --tag 2026.10.9

升级建议: 观望 (暂不升级)
理由:
1. 硬性前置未满足 —— 需先升级 Node 至 24.22.1 / 26.12.1+，属于会动到运行时环境的操作，需人工确认后执行。
2. 2026.10.9 存在 5 个未修复的 critical/high issue，10.10 尚在 beta，等 10.10 转正或 2026.10.11 更稳妥。
3. 当前 2026.9.5 运行正常，无紧急故障触发升级。
建议路径（待人工确认后执行）:
  a. 确认 Node 升级窗口 → brew upgrade node 到 26.12.1+ 或改用 24.22.1
  b. 备份 OpenClaw 状态与配置
  c. 目标先取 2026.10.7（已知问题更少），待 2026.10.10 转正后再跟进
  d. 升级前 `openclaw update --dry-run`，升级后跑 doctor 并重启 Gateway
备注: 如需“立刻拿到安全补丁”，可关注 2026.10.10 转正时间；但 fast-uri/nodemailer/MSAL 依赖风险需自行评估是否可接受继续跑 2026.9.5。
