# OpenClaw 版本监控报告
日期: 2026-06-15

## 版本对比
- 当前运行版本: 2026.5.28 (2026-05-28, commit e932160)
- 最新稳定版本: 2026.6.6 (npm latest, 约 2026-06-14)
- 最新 beta: 2026.6.8-beta.1 (2026-06-14)

## 是否有新版本
✅ 有新版本 — 2026.6.6 比当前运行版本 2026.5.28 更新

## 重大变化评估
2026.6.x 是一个大规模稳定性和平台更新版本，主要包括：
- 通道安全强化（channel safety）
- MCP 和 Anthropic 恢复能力增强
- 内置 Parallel Web Search（免费并行搜索）
- 改进的 Google Vertex 支持
- Feishu（飞书）、WhatsApp、Telegram、Matrix 等通道改进
- 更可靠的 Agent 恢复路径和 SQLite-backed session state
- Plugin 和 Skill Workshop 工作流强化
- 平台维护：Android、Swift/macOS、Docker、CodeQL 依赖更新

## 历史背景参考
- 5.5 版本存在 xAI 兼容问题
- 5.6 热修了 5.5 的问题
- 当前 6.x 稳定版本已修复大量 5.x 遗留问题

## 升级建议
⚠️ 建议升级

理由：
1. 2026.6.6 是稳定性大版本，大量真实使用场景的稳定性修复
2. 内置 Parallel Web Search 功能对 Agent 工作有实质帮助
3. 飞书通道有明确改进（Feishu behavior improved）
4. 从 5.5 → 5.6 → 6.x 的演进路径已较成熟
5. 当前运行 2026.5.28，已落后约 3 周，建议升级到 2026.6.6

## 操作建议
升级命令: openclaw update --channel stable
或在 npm: npm i -g openclaw@latest

## 下次监控
建议 3 天后再次检查是否有 2026.6.7 / 2026.6.8 稳定版发布
