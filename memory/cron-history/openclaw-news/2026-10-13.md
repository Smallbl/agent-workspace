## ⚠️ 即将变化（注意兼容性）

据社区反馈，v2026.10.1 引入了以下破坏性变更：
- metadata.clawdbot → metadata.openclaw（所有技能和 Hook 需迁移）
- Discord 语音 TTS 设置已停用
- 定时任务现在继承所属对话的工具权限
- 内存搜索客户端需迁移至 API v2

**建议：** 当前 v2026.9.5 稳定，建议等待 2026.9.10+ 再升级，避开首批迁移问题。

🔗 https://www.facebook.com/groups/claudecommunity/posts/1144095084797822

## 【豆浆学习笔记】

### 关键洞察

1. **Control UI 多会话并行** — 最有价值的日常改进
   - 同时打开多个会话窗格，减少标签页切换
   - 建议等功能稳定后优先体验

2. **将历史对话转为可复用技能** — 知识沉淀机制
   - 复杂问题处理流程可固化为模板
   - 长期利好团队知识积累

3. **回滚保护增强** — 安全性提升
   - 更新更有保障，故障可恢复
   - 对稳定运行至关重要

4. **v2026.10.1 破坏性变更** — 保持当前版本
   - metadata 重命名涉及所有技能
   - 建议等待 2026.9.10+ 再升级

5. **OpenClaw Enterprise** — 未来私有化部署备选
   - 说明产品已被主流认可

### 📌 总结
目前 v2026.9.5 是稳定的好版本，不需要急着升级。新功能了解即可，等社区反馈充分后再行动。
