### 1. v2026.10.5 发布：侧边栏重构、Skill Workshop 2.0、公开会话链接
2026-10-18 发布的 v2026.10.5 是近两周规模最大的一次更新，包含 2,250 个 PR、411 次直接提交、637 位贡献者。三个最值得注意的变化：侧边栏把 Agent 列表改成可读行并支持搜索与置顶，Subagents 与 Processes 面板与父会话并排显示，可以直接查看委派任务、查看最近命令输出或终止任务；Skill Workshop 增加了"已保存版本"和"撤销（Undo）"能力，让技能改写更安全；发布后的会话可在正常聊天链接上直接打开，任何拿到链接的人都能免登录阅读记录（脱敏仅为尽力而为，关闭共享无法召回已保存副本）。这版还进一步强化了升级/重启的恢复能力，X 渠道和语音通话也有所增强。
原文链接：https://docs.openclaw.ai/releases/2026.10.5
补充报道：https://www.theclawreport.com

### 2. v2026.10.4：升级后聊天卡死"Server updated"问题被修复
2026-10-16 发布的 2026.10.4 是一次专注稳定性与升级恢复的补丁版（55 个 PR、49 位贡献者）。核心是 Web UI 修复：升级前打开的聊天标签页会卡在"Server updated"，现在刷新即可回到同一会话链接；同时修复了电脑休眠/系统时钟回拨引起的不必要中断、Gateway 停止或重启时因会话索引卡死而挂起的问题（重启后已保存的转录仍可读）、Mac 端从外部终端重启被误拒的假报错，以及 Tailscale 阻断启动时 Doctor 现在能明确告诉你是需要重连、登录还是申请管理员审批。安全方面修复了 Tlon 群聊私信权限：未验证的群成员身份声明不再能获得 owner 命令、审批/管理员操作或提权工具权限。

主版本迭代到 10.x 的同时，官方发布了仅包含 Gateway 的 extended-stable（等价于 LTS）分支 2026.9.33：它是 2026 年 9 月底的主线代码，加上关键安全更新、可靠性与性能修复以及新模型支持。这条线版本号更"旧"，但可回溯性更强，适合生产环境求稳。社区播客专门讨论了"新版本号反而更旧"的这一现象、backport 修复能保证什么不能保证什么，并给出升级路径选择建议与自动化验收清单。

### 4. 记忆与检索链路持续加固：嵌入失败自动降级、远程工作区可读 Memory 文件
9.6 / 9.7 / 10.5 几个版本都把重点放在 Memory 的稳定性上：可选的 embedding 服务失败时，记忆搜索会自动回退到已有的关键词索引（显式指定远程 provider 时仍报错），中英混合提问中保留英文词匹配；embedding 缓存迁移改为分批进行并报告超大行，避免一次迁移卡死；2026.9.7 还修复了记忆更新遗漏与搜索失败，并给出 Dreaming 调度与独立 QMD 文件的保护。2026.9.6 起，workspace adapter 可以把远程主机上的 Memory 文件暴露给本机检索、读取与维护（需单独配置 memoryFiles 适配器，改源后要跑 `openclaw memory index --force --agent`）。此外历史对话标题、ACP 元数据、transcript 标记等历史修复被收进 Doctor 维护流程，不再在日常启动时重写历史。

## 【豆浆学习笔记】

**我们当前跑在 2026.9.5，比官方最新稳定版 2026.10.5 落后了一个多月**，中间跨越了 10.1/10.2/10.4/10.5 四个版本，其中包含大量升级恢复和稳定性修复——这是最直接的行动项。

**可立即应用到我们工作流的点：**

1. **升级前必须做带校验的备份**（`openclaw backup create --verify`）。10.2/10.4 的官方说明反复强调：数据库 schema 迁移是单向的，降级安装包回不去，唯一受支持的恢复方式是用匹配旧版本的备份还原。这跟我们 AGENTS.md 里"改配置前先备份"的铁律是同一逻辑，现在有了官方命令和官方背书。
2. **升级后的固定三连验证**：`openclaw --version` → `openclaw doctor` → `openclaw status`，再刷新升级前开着的聊天标签页并发一条测试消息（尤其是飞书通道）。10.4 的核心修复就是"升级后聊天卡在 Server updated"。
3. **升级仍走 `~/.scripts/safe-gateway-restart.sh`**。10.4 修复了 Gateway 关闭时挂起的问题，但我们自己的 10 秒缓冲脚本依然值得保留——它解决的是"消息正在处理中被 SIGTERM 打断"的问题，官方修的是索引卡死，层次不同。
4. **记忆检索的关键词降级机制对我们价值很大**。飞书上每天进来的中英混合内容较多，embedding 服务偶发失败时能自动回退关键词索引，等于给记忆层加了一层容错。如果我们现在还在用远程 embedding provider，建议排查一下 `min_score` / `max_results` 参数与 provider 选型。
5. **Skill Workshop 的"已保存版本 + Undo"值得试**。我们已经有自改进机制和技能文件，后面如果开始系统性地做技能改写（尤其涉及 prompt 和流程的那种），能回滚就敢改，风险显著降低。
6. **Subagents / Processes 面板与父会话并排**（10.5 新增）。这正好对上王"多项目并行推进"的痛点——可以把项目跟踪、待办盯办这类工作做成可见的子任务面板，而不只是等结果通知。
7. **public conversation links 要谨慎**。这功能方便把一份分析结果直接发链接给同事，但"脱敏仅为尽力而为"、关闭共享无法召回已保存副本——涉及公司招投标项目的敏感内容，坚决不要用这个功能外发。

**对新模型的态度**：Claude Opus 5.5 / GPT-6.1 Sol / Haiku 5.5 都已可用，provider-native compaction 也上了，可以小成本试一轮——但注意我们当前主模型是 minimax/MiniMax-M2.7，换模型前先评估长会话和飞书多轮场景的稳定性，别在定时任务跑着的时候切。

**下一步建议**：这周找一个当前无消息处理的窗口，按"备份 → 升级 → doctor → status → 飞书发测试消息"五步走，把版本从 2026.9.5 推到 2026.10.5。要我择时执行吗？
