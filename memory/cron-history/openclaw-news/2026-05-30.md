### 1. v2026.5.28 安全加固与 Pixverse 视频生成正式上线
**发布时间：2026年5月28日**

本次更新是5月安全强化周期中聚焦度最高的一次，主要变化：

- **安全边界全面加固**：群组提示词元数据被阻止进入系统提示词、Tailscale无认证暴露被封堵、节点/设备角色审批现在需要管理员权限
- **Codex 运行更稳定**：Codex 应用服务器运行稳定性显著提升
- **Pixverse 视频生成成为一类_provider**：新增 Pixverse 作为官方视频生成提供商，支持 API 区域选择和外部插件打包支持，Agent 可以直接调用生成视频剪辑

这意味着我们的 Agent 现在具备了直接生成视频内容的能力，可应用于文档生成演示、内容创作等场景。

### 4. ⚠️ 安全警报：Claw Chain 攻击 — 必须尽快更新
**披露时间：2026年5月26日（IANS Research）**

OpenClaw 存在"Claw Chain"链式漏洞攻击，可将其部分沙箱转化为完全主机入侵的跳板。

**关联4个 CVE：**
- CVE-2026-44115 — 存储 API 密钥和提供商凭据的逻辑缺陷
- CVE-2026-44118 — 提权至主机级权限
- CVE-2026-43527 和 CVE-2026-43582 — 金融安全局并行警告中的关键缺陷

**重要提醒**：如果 OpenClaw 部署在有暴露风险的网络环境中，必须优先安排安全更新。

**原文链接**：https://www.bighatgroup.com/blog/openclaw-weekly-2026-05-26

## 【豆浆学习笔记】

### 💡 这些更新对我和团队的价值

**1. 安全优先 — 最高优先级**
Claw Chain 攻击的披露提醒我们：OpenClaw 的沙箱不是银弹。如果服务部署在有外部访问面的环境中，必须：
- 尽快确认当前版本是否已包含上述 CVE 修复（当前运行 v2026.5.18，较新，应该已包含）
- 避免给 Agent 开放过高权限的文件系统访问
- 避免在 Agent 可读取的路径中放置敏感文件

**2. 文件获取的安全变化最值得关注**
v2026.5.26 开始，fetched file text 被标记为外部不可信内容。这意味着：Agent 读取文件时，文件中的指令不再等同于操作员指令。这是一个重要的安全改进。

**3. Pixverse 视频生成 — 新能力探索**
如果需要为工作场景（标书演示、培训视频）生成视频内容，可以探索 Pixverse 集成。这个功能打开了新的内容创作可能性。

**4. Gateway 启动性能提升**
我们在 Mac Mini 上运行，v2026.5.18 的启动性能可能还有优化空间。如果 Gateway 重启频繁，可以关注是否有改善。

**5. 技能系统更新 — 需要注意**
SKILL.md Breaking Change 提示：部分技能可能需要迁移以适应新版本。后续升级时应留意技能兼容性。
