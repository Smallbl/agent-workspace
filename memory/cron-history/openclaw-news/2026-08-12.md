## 一、Extended-Stable 长支持通道正式上线

OpenClaw 正式推出 Extended-Stable 长期支持版本，基于 2026.6.11，首个版本为 2026.6.33（现已更新至 2026.6.34）。该通道每月发布一次，专注安全与可靠性修复回填，不添加新功能。npm 命令：`npm install -g openclaw@extended-stable`。同时推出"功能成熟度评分卡"（Maturity Scorecard），让运维人员清楚了解每个功能的质量与完整度。

**对我们**：目前使用稳定版通道即可；如需更保守的升级策略可切换到 extended-stable，尤其在生产环境关键任务时。

🔗 https://releasebot.io/updates/openclaw

## 二、内存记忆按项目隔离——跨项目记忆泄露已修复

OpenClaw Main 分支合并了一项关键安全修复：之前 curated memory 会在不同项目之间共享，造成上下文泄露。现在每个项目的记忆严格隔离，系统在语义记忆不可用时会优雅降级为关键词搜索。

**对我们**：重要安全改进，按项目分类存放敏感内容更安全。

🔗 https://openclaw.academy/releases

## 三、GPT-5 长上下文改为明确 opt-in，默认降为 272k tokens

OpenClaw 主线已修复 GPT-5.5 和 GPT-5.6 的百万 token 上下文问题——默认运行预算现在为 272,000 tokens，不再默认使用超长上下文。需要更长上下文（成本更高）的用户需要主动选择开启。

**对我们**：如果使用 GPT-5 系列模型，默认更安全可控。

🔗 https://openclaw.academy/releases

## 四、Heartbeat 任务全面迁移为 Cron 调度，原 HEARTBEAT.md 退役

OpenClaw 主线将旧的 Heartbeat 任务机制彻底迁移为基于 Cron 的调度系统，HEARTBEAT.md 也被 SQLite 后端的安全暂存区替代。升级后 Doctor 命令可以自动处理迁移。

**对我们**：豆浆的 heartbeat 机制应该迁移到新的 cron 风格。AGENTS.md 中 heartbeat 相关描述需要更新。

🔗 https://openclaw.academy/releases

## 五、问题卡片与审批系统全面升级

Agent 现在可以在 Web、聊天频道、macOS 和原生应用中发送结构化的选项卡片向人类提问，审批流程支持推送通知、审批历史、公平队列、无头审批解决等。人机协作闭环更加完整。

**对我们**：最有价值的生产力提升点——可以让 agent 在需要判断的事项时主动提问，同时保持不中断执行流。

🔗 https://openclaw.academy/releases

## 六、Logbook 上线：AI 生成工作日志与 standup

Logbook 是 v2026.7.1 引入的新功能，可以按时间线自动整理一天的工作记录，生成 standup 汇报，并支持针对当天活动提问。数据仅保存在本地，主人独有，可配置保留期限。

**对我们**：适合每日自动化汇报场景。

🔗 https://docs.openclaw.ai/releases/2026.7.1

## 七、ClawHub 安全事件提醒：供应链攻击风险

2026年6月初，攻击者在 ClawHub 上传了超过 1100 个伪装成生产力工具的恶意 skills（代号 ClawHavoc）。一旦安装，恶意 skill 在 agent 信任边界内拥有完整权限。

**对我们**：ClawHub 安装 skills 前必须审核代码，不使用未经审查的第三方包。

🔗 https://www.uscsinstitute.org/cybersecurity-insights/blog/openclaw-security-crisis-unpacking-agentic-ai-risks-in-2026

## 八、移动端重大更新：iOS + Android 语音功能全面升级

2026.7.1 对 iOS 和 Android 进行了大规模更新，语音功能体验大幅改善，界面支持多语言本地化，移动端通知交互更完善。

**对我们**：如果后续有手机配对节点需求，移动端语音能力现在更加可用。

🔗 https://docs.openclaw.ai/releases/2026.7.1

## 九、CLI 安全改进：session 管理命令新增 archive/delete

Headless 场景现在可以通过 Gateway 命令安全地 dry-run、归档和删除指定 session，无需手动编辑 SQLite 数据库，降低了数据损坏风险。

**对我们**：适合服务器运维场景，session 清理更安全。

🔗 https://openclaw.academy/releases

## 十、"Agent Scheduler Tool" 正式更名为 "Automations"

原"Agent Scheduler Tool"已统一改名为"Automations"，命令别名已添加，与旧的 Cron 配置完全兼容，迁移透明无需改配置。

**对我们**：文档和描述需要同步更新术语。

🔗 https://openclaw.academy/releases

## 豆浆学习笔记

### 核心趋势
2026年8月的 OpenClaw 正处于从"快速迭代"向"企业级可靠"转变的阶段：
1. **稳定性优先** —— 大量 PR 在修 crash、data loss、message loss
2. **安全成标配** —— 记忆隔离、供应链审核、credentials 脱敏、opt-in 成本控制
3. **人机协作深化** —— 问题卡片+审批系统让 agent 主动提问更自然
4. **移动端成熟** —— iOS/Android voice 能力大幅改善

### 值得我们尝试的
- 问题卡片机制：设计"需要王决策时主动发选项卡片"的模式
- Logbook + Cron 联动：用 Logbook 生成每日工作摘要，配合 cron 自动推送飞书
- extended-stable 通道：生产环境可以考虑切换
- HEARTBEAT.md 退役：更新 AGENTS.md 中 heartbeat 相关描述

### 需要警惕的
- ClawHub 供应链风险——任何第三方 skill 安装前必须审核代码
- Beta 版本仍在快速迭代，生产环境避免使用
