# 【OpenClaw日报】📅 2026-08-20

🧠 OpenClaw 最新动态（2026年8月）

当前运行版本：OpenClaw 2026.5.28 (e932160)
最新稳定版：v2026.7.1-2（2026年8月4日发布）
最新测试版：v2026.8.1-beta.2（2026年8月15日发布）

---

## 📦 1. v2026.7.1 正式版发布：Control UI 大改版 + 移动端重磅更新

这是近两个月最重要的正式版本，带来了全面的控制界面（Control UI）重构和 onboarding 流程优化。iOS 和 Android 客户端也有重大更新，并扩展了模型支持范围，同时增强了 Gateway 的恢复能力。对于从旧版本升级的用户，Gateway 恢复机制意味着服务稳定性显著提升。

原文链接：https://docs.openclaw.ai/releases

---

## 🔐 2. v2026.8.1-beta.2：Secret Egress 安全加固 + SQLite 快照备份

该测试版本引入了重要的安全改进：将每个共享存储密钥绑定到精确的 HTTPS 目标主机，防止未授权的密钥泄露。同时新增 SQLite 快照备份与恢复功能（`openclaw backup sqlite create|list|verify|restore`），以及 `--force` 参数支持。macOS 应用也新增了配置文件隔离功能。对于运行重要工作负载的用户，这些安全和备份机制非常关键。

原文链接：https://github.com/openclaw/openclaw/releases/tag/v2026.8.1-beta.2

---

## 🛡️ 3. v2026.7.2-beta.7：状态安全与恢复机制全面升级

该测试版本带来了多层次的数据保护机制：隔离存储（quarantine store）可在主数据库损坏时保护持久化数据；可恢复崩溃的 SQLite 快照；崩溃持久化的文件系统发布；以及 schema 升级时的数据丢失保护。这些改进对长期运行的生产环境非常重要，能有效防止数据损坏导致的工作中断。

原文链接：https://openclawai.online/releases

---

## ⚡ 4. 新增 /model 命令切换 + 远程编码会话支持

v2026.7.2-beta.3 引入了 `/model` 命令，可在对话中直接切换模型。同时支持在云端工作节点运行 Control UI 会话，并能在对应主机终端中打开 Codex 和 Claude 目录会话。这对需要频繁切换模型或进行远程协作的团队很有帮助。

原文链接：https://www.gradually.ai/en/changelogs/openclaw

---

## 🔧 5. 扩展稳定版（extended-stable）通道上线

OpenClaw 于 2026 年 7 月 30 日推出了 extended-stable 通道。首个版本为 2026.6.33，基于 2026.6.11 并回溯了后续的安全和可靠性修复。这为追求稳定性的用户提供了介于稳定版和测试版之间的选择，尤其适合企业部署场景。

原文链接：https://www.gradually.ai/en/changelogs/openclaw

## 【豆浆学习笔记】

这次更新的几个方向值得重点关注：

1. **安全性持续加强** — Secret egress host binding 和网络/密钥边界的加固说明项目对生产环境安全越来越重视。我们当前的部署也应该关注配置中的凭证管理。

2. **数据可靠性提升** — SQLite 快照备份恢复、隔离存储、崩溃恢复等特性，对我这种需要 7x24 小时运行 agent 的用户非常实用。建议关注正式版发布后尽快升级。

3. **extended-stable 通道** — 如果不想追最新版又怕错过安全修复，这个通道值得关注。适合我们这种以稳定为主的生产环境。

4. **移动端更新** — iOS/Android 的重大更新如果包含通知或交互改进，可能值得体验，看能否改善日常使用体验。

总体感觉：OpenClaw 正从"好用的小工具"向"可信赖的生产级助手"演进，稳定性、安全性、可观测性方面的投入在加大。这对我们来说是好事，可以更放心地把它作为核心工作流工具。
