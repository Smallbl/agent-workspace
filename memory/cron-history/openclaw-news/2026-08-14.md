### 2️⃣ OpenClaw 2026.7.2-beta：可靠性与协作重大升级（8月2日）

Beta 版本带来一系列重磅新特性，大幅提升生产级稳定性。

- 抗崩溃数据恢复：崩溃后可自动恢复，Session 不会中断
- 持久化 Channel 投递：消息传递更可靠
- Session 倒带与分支：可回溯历史 Session 状态，支持分支探索
- 更丰富的 MCP 应用和仪表板集成
- 改进的本地推理支持，新模型和 Provider 选项

🔗 https://releasebot.io/updates/openclaw

### 3️⃣ 扩展稳定版本（Extended-Stable）机制上线

OpenClaw 正式引入"LTS"风格的支持策略。

- 每月发布一次扩展稳定版（基于当月早期版本）
- 安全和可靠性修复会向后移植到扩展稳定版
- 版本命名规则：YYYY.M.33（如 2026.6.33）
- 每个扩展稳定版至少维护一个月
- 为企业级用户提供更长生命周期支持

🔗 https://petronellatech.com/blog/openclaw-ai-agent-guide-2026

### 4️⃣ Talk Mode 本地语音合成登陆 macOS（4月引入，持续完善）

Apple Silicon Mac 用户现在可以完全本地运行语音交互。

- 通过 MLX 框架实现，完全离线可用
- 无需云端 API，隐私保护更好
- 2026.4.12 版本已修复多项稳定性问题
- 适合对数据安全有要求的企业内网部署场景

🔗 https://petronellatech.com/blog/openclaw-ai-agent-guide-2026

---

### 5️⃣ 安全加固系列：跨组件信任与网络边界强化（3-4月）

3-4月间推送了项目史上最大规模安全更新。

- 远程节点事件默认标记为"不可信"，防止注入 System Prompt
- WebSocket 会话在密码/Token 轮换后立即失效（不再等待自然过期）
- Skills 目录增加 realpath() 验证，防止目录穿越攻击
- 敏感环境变量注入拦截，防止恶意覆盖
- 所有内置 Channel 改为标准化 setup/secret 合同机制加载

⚠️ 如在生产环境或多用户系统运行，务必升级到此版本段

🔗 https://openclaw.report/news/openclaw-2026-3-12-release

### 6️⃣ Event-Driven Cron 定时任务（2026.7.1-beta.2+）

定时任务支持"命令完成后触发"事件。

- 传统 Cron：固定时间触发，可能空跑或延迟
- 新机制：命令结束立即唤醒 Agent，响应更快
- 适合监控长时间运行任务，完成后自动处理结果

🔗 https://openclawai.io/blog

---

### 7️⃣ Active Memory 插件升级（2026.4.10+）

上下文记忆能力从"静态"升级为"动态检索"。

- 旧版：Session 启动时加载 MEMORY.md，之后不再更新
- 新版：运行时动态检索相关记忆片段
- 结合 memory_search 工具，跨 Session 关联能力更强
- 减少重复劳动，提升长期任务连贯性

🔗 https://petronellatech.com/blog/openclaw-ai-agent-guide-2026

---

### 8️⃣ QMD Skill：本地混合搜索技能

新增本地记忆文件、笔记和 Session 转录的混合搜索能力。

- 内置 memory 搜索不够用时的增强方案
- 支持跨 memory 文件夹、笔记、Session 记录检索
- 查资料更快，减少人工翻找时间

🔗 https://openclawai.io/blog

## 🧠 豆浆学习笔记

### 📌 版本差距提醒

当前本地运行的是 **2026.5.28**，而稳定版已到 **2026.6.34**，差了大约2个月的功能和大量安全修复。**建议尽快安排升级。**

### 💡 可直接应用到我们工作流的功能

1. **【Session 倒带与分支】** - 多步任务中途出错时可以直接回退，不用重新开始，省时间
2. **【Event-Driven Cron】** - 监控类任务（如图纸比对、文件同步）完成后立即触发处理，比轮询更高效
3. **【Active Memory 动态检索】** - 长期项目跟进时，记忆检索更准确，减少重复解释背景
4. **【持久化 Channel 投递】** - 飞书消息传递更可靠，不丢消息

### 🔮 值得尝试的新特性

1. **【QMD Skill】** - 适合知识库检索场景，比如历史项目文档搜索
2. **【本地语音合成（MLX）】** - 我们用 Mac Mini，理论上可以试验离线语音交互
3. **【扩展稳定版策略】** - 如果未来有企业级需求，可以考虑用 LTS 版本降低升级频率

### ⚠️ 安全提示

3-4月的安全加固系列是**必升级项**。如果当前系统暴露在外网或有外部用户访问，尤其要尽快升级到包含这些修复的版本。
