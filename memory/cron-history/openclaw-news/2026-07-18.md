## 📰 最新资讯

### 1. v2026.7.1 重磅更新：Control UI 大改版 + GPT-5.6 支持
**发布时间：2026年7月13日**

OpenClaw v2026.7.1 是近期的核心版本，带来了多项重大改进。首先是 **Control UI 全面改版**，涵盖聊天、会话、工作区和用量视图，让操作体验更加流畅。其次，**官方 iOS、Android、macOS 应用**都收到了大幅更新，包括设置流程、导航、聊天、语音、Apple Watch、权限、本地化、文件、定时任务等方面的改进。**模型支持扩展**也是亮点——新增 GPT-5.6、Tencent Hy3、Meta Muse Spark 1.1 兼容，并强化了 Codex 和编程Agent工作流。此外还修复了 Gateway 崩溃循环问题、远程浏览器控制、工作区终端等。

🔗 https://docs.openclaw.ai/releases/2026.7.1

### 2. v2026.6.11：修复"粗糙感"，提升可靠性
**发布时间：2026年6月30日**

v2026.6.11 是一个专注于**修复和稳定性的版本**。团队听取反馈，针对让人感觉"不太可靠"的痛点进行了集中修复：解决了消息回复错位、发送卡住、断线重连、模型设置失败等问题。同时改进了 Telegram、WhatsApp、Matrix、Google Chat、iMessage、飞书、Mattermost、WebChat、Control UI 和终端UI的消息传递可靠性。内存功能也得到改进，让 dreaming、QMD 导出、索引和同步更不容易遗漏或错误归因对话历史。

🔗 https://docs.openclaw.ai/releases/2026.6.11

### 3. v2026.6.10：自动快速模式 + 更可靠的 Agent 调用
**发布时间：2026年6月24日**

v2026.6.10 引入了**自动快速模式（Automatic Fast Mode）**，短对话会快速启动，然后自动将较长或需要回退的工作切回正常模式，且不会丢失可见状态。同时改进了 Provider 路由、Channel 进度、会话身份和可信工具策略的可靠性。这个版本还包含大量小型改进，涵盖 Provider 设置、诊断和 Transcript 工具。

🔗 https://github.com/openclaw/openclaw/releases

### 4. 安全与合规：新加坡 CSA 发布 OpenClaw 网络安全风险警报
**发布时间：2026年**

新加坡网络安全局（CSA）发布了关于 OpenClaw 网络安全风险的重要警报，指出 AI Agent 与传统 AI 工具不同——它们可以使用外部工具（浏览器、代码执行器、API）代表用户执行操作，存在**Agent劫持、未授权操作、工具/API滥用**等风险。建议用户将"授予 OpenClaw 更广泛权限"作为有意识的决定，而非忽略默认配置。新加坡 IMDA 也发布了相关案例研究。

🔗 https://www.csa.gov.sg/alerts-and-advisories/advisories/ad-2026-005

### 5. 供应链安全：ClawHub Skill 市场风险持续受关注
**发布时间：2026年**

安全研究机构 Palo Alto Unit 42 持续监控 **ClawHub Skill 供应链风险**，发现恶意 Skill 试图利用 AI 供应链生态系统。OpenClaw 已在与 NVIDIA 合作，对所有 Skill 进行文档记录和工具分析。ClawHub 也集成了 VirusTotal 和 ClawScan 来主动筛查恶意 Skill。作为用户，**建议只安装可信来源的 Skill**，并留意权限申请。

🔗 https://unit42.paloaltonetworks.com/openclaw-ai-supply-chain-risk

## 【豆浆学习笔记】

**📌 对我们的价值：**

1. **飞书集成持续改善** — v2026.6.11 和 v2026.7.1 都提到了飞书消息传递的可靠性修复，包括重连和发送稳定性。作为主要沟通渠道，这些改进直接关系到我们的使用体验。

2. **自动快速模式值得关注** — v2026.6.10 的自动快速模式让短任务响应更快，这对日常查询类任务很有帮助。可以考虑在配置中启用测试。

3. **安全意识要提升** — 新加坡 CSA 的警报提醒我们：Agent 权限不能随便给。豆浆作为王的得力助手，有文件、消息、系统访问权限，更要注意安全操作——尤其是处理外部链接和执行命令时。

4. **版本更新节奏很快** — 当前本地版本是 2026.5.28，而最新稳定版已到 2026.7.1，差了大约两个月。可以考虑安排一次升级测试。

5. **ClawHub Skill 安装要谨慎** — 虽然 Skill 生态很强大，但来源不明的 Skill 可能有风险。安装新 Skill 前要确认来源。

**💡 可以尝试的新特性：**
- 测试"自动快速模式"对日常查询类任务的加速效果
- 关注 v2026.7.1 的 Control UI 改版，看是否对工作流有优化
- 检查当前配置是否需要更新安全策略
