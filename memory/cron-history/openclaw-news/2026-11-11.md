■ 资讯 1｜2026.11.3（latest）发布：子任务可见性 + 凭据隔离大扫除
无新配置项，纯修复型 release。核心是让"看不见的失败"变可见：未回应的工具失败不再静默以成功结束对话（#182458）；私有子 Agent 的完成结果不再泄漏到流式聊天回复中（#188490）；父 Agent 取消子任务后可无阻塞地交接给替补任务（#178893）。同时做了一轮凭据收敛：插件缓存结果按连接凭据隔离、Firecrawl 搜索/抓取密钥跟随各自端点、配置读取时脱敏内联环境变量凭据、子进程不再继承无关的 Gateway 密钥（#179198/#179415）。
https://github.com/openclaw/openclaw/blob/main/CHANGELOG/2026.11.3.md

■ 资讯 2｜2026.11.2：113 个 PR 的大补丁，重点在"更新别再卡死"与"提醒别再丢"
官方定位为无新功能的补丁版，但工程量很大（113 PR / 53 commits / 64 个贡献者）。更新链路被系统性加固：快照检查超时后的安全恢复、更新结果里被吞掉的警告、profile 更新读错数据库、中断更新后仍等待 Gateway 就绪等；Web UI 侧修掉重复 Canvas 小组件、Agent Files 草稿误存到别的 workspace；消息侧修掉 WhatsApp 私信丢失、Telegram 轮询重试拖慢 Gateway 关机、Discord 昵称歧义误 @ 人。
https://docs.openclaw.ai/releases/2026.11.2

■ 资讯 3｜2026.9.37（extended-stable / 当前 LTS 等价线）发布
gateway-only 版本，基于 2026 年 9 月底主线 + 关键安全更新。亮点：配对节点的拍照/截图默认不再自动附到回复里（隐私默认收紧）；会话在 /new、/reset、空闲或每日滚动后保留已关联的模型账号；更新中断后保留回滚点；修复 MCP loopback 监听意外关闭导致后续工具调用永久断开的问题；并明确"配置重启在重启信号围栏之外准备"。

【豆浆学习笔记】
1. 本机 Node 是 v26.7.0，正好卡在 latest（需 >=26.1.0，能装）与 extended-stable 2026.9.37（需 >=26.12.1，装不了）之间。也就是说现在这台机器能升 latest，但**不能**切到 extended-stable 线——要留 LTS 就得先把 Node 升到 26.12.1 以上。这条是本次最值得记住的实操结论。
2. 2026.11.3 的"未回应的工具失败不再静默当成功结束"和"私有子 Agent 结果不泄漏到聊天流"，正好命中我们的痛点：AGENTS.md 铁律里"子Agent回复前自检 + 主Agent必检项"此前只能靠约定，平台层现在会把失败显式抛出来，编排可靠性提升，可考虑把"子Agent 回执自检"也落成对失败回执的显式处理。
3. 本机 doctor 报 2 个孤儿 agent 目录（agent-frontend、backend-agent）——是历史专业 Agent 架构遗留。配置里已无对应 agents.entries。既然主 Agent 架构（豆浆一人）已经定型，这 2 个目录可清理，但 AGENTS.md 铁律仍按"派发子 Agent"写，需要同步把文档口径改成"用 sessions_spawn 而非专用 agent 目录"，否则文档和本机状态会长期背离。
4. 2026.11.3 的凭据隔离与子进程不继承无关密钥，与我们用 exec 驱动 shell 的场景直接相关——涉及"backup / 版本监控"这类自动化时，环境变量污染风险下降，可继续沿用当前做法。
5. 关于"配置变更是否必须重启"：本次只从 2026.9.37 原文读到"配置重启在重启信号围栏之外准备"这一条描述，并在 2026.11.3 的 dist 包里确认存在 `restartPending` 相关实现字符串（gateway-prewarm.js）；未找到 "applied-restart-required" / "restart-pending" 这类 outcome 字符串（阳性对照：同一匹配逻辑能命中 CHANGELOG 与 gateway-prewarm.js 中的 restart 相关文件，属真实未命中）。因此本简报不下"不强制重启"或"不再丢消息"的结论；现行 AGENTS.md 的安全重启规范继续保留。
