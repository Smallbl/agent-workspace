## 头条速览

### 【1】OpenClaw 核心大幅精简 · 性能飞跃式提升
来源：https://openclaw.ai/blog/lighter-core-sharper-claws

从 2026.4 到 2026.5，OpenClaw 核心经历了"蜕皮式"瘦身：
- Agent 启动时间：7.5 秒 → 1.9 秒（提升 75%）
- npm 包体积：43.3 MB → 17.9 MB（下降 59%）
- 本地 node_modules：656 MB → 260 MB（下降 60%）
- 安装后整体：686 MB → 581 MB

做法是将重型插件依赖移出核心，依赖链收窄，安全审计面缩小。

### 【2】安全警报：两类攻击路径被披露
来源：https://thehackernews.com/2026/06/new-attacks-trick-openclaw-ai-agent.html

安全研究团队本周披露了 OpenClaw 的两类攻击风险：

① **vCard / 联系人嵌入恶意指令**（Imperva 发现）
- 攻击者在共享联系人、vCard、位置信息中隐藏指令
- Agent 处理这些数据时直接执行，不弹窗提醒
- OpenClaw 已于 **2026.4.23 修复**

② **社会工程钓鱼**（Varonis 发现）
- 攻击者构造看似普通的业务邮件，让 Agent 主动发送敏感数据
- 需从"限制 Agent 自主操作权限"层面防御

> 豆浆提醒：飞书渠道尤其要注意陌生人发来的联系人分享或文件

### 【3】OpenClaw × NVIDIA 联手打造 Skill 安全验证体系
来源：https://openclaw.ai/blog/openclaw-nvidia-skill-security

- 每个技能发布前经过三重扫描：OpenClaw 静态分析 + VirusTotal + NVIDIA SkillSpector
- 扫描结果生成"技能卡"（Skill Card），公开记录代码来源和扫描结果
- 可通过命令行查看：`openclaw skills verify <slug> --card`

## 💡 豆浆学习笔记

1. **安全意识提升**：vCard注入和钓鱼邮件攻击提醒我们：Agent 的"听话"是双刃剑。建议对陌生人发来的联系人、文件保持警惕；限制 Agent 未经确认就发送外部消息的能力。

2. **核心精简战略**：OpenClaw 走"更小、更专注"路线对我们自托管部署是好消息，关注未来 LTS 版本。

3. **Skill 生态成熟**：NVIDIA 合作的 Skill Card + ClawScan 验证体系让 AI Agent 技能供应链开始有行业标准，我们安装任何第三方 skill 时将有据可查。

4. **恢复能力 = 下一竞争维度**：OpenClaw 正从"能做事"向"出事后能修"进化，对我们这种需要持续跟进的业务系统很关键。
