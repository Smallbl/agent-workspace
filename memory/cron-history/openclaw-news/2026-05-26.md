## 🔹 OpenClaw 2026.3.12：安全与架构双重升级

这是2026年3月的一次重大更新，重点不是单点功能，而是把OpenClaw从"能跑"升级为"更适合长期部署、多人协作和生产使用"。

**核心变化：**
- **Control UI v2**：网关控制台重构为模块化视图（overview/chat/config/agent/session），新增命令面板、 slash commands 、搜索导出和置顶消息等功能，大幅降低使用门槛
- **设备配对安全修复**：配对码从长期共享 token 改为短时 bootstrap token，避免凭证泄露风险
- **Workspace Plugin 安全收紧**：工作区插件必须进入显式 trusted 状态才能执行，防止恶意代码自动运行
- **/fast 快速模式统一化**：跨模型（OpenAI/GPT-5.4、Anthropic/Claude）、跨入口（TUI/Control UI/ACP）统一支持

**价值**：这次更新让OpenClaw更接近"统一运营后台"，适合团队部署场景管理。

## 🔹 EnterpriseClaw：企业级AI Agent治理平台诞生

**价值**：这代表AI Agent在企业市场的成熟度提升，未来我们的招标/采购场景可以考虑引入这类治理能力。

## 🔹 安全警报：OpenClaw修复6个新漏洞（2026年2月）

安全厂商Endor Labs披露了OpenClaw的6个新漏洞，涉及服务器端请求伪造（SSRF）、身份验证缺失、路径遍历等问题，部分漏洞有公开利用代码。

**关键漏洞：**
- CVE-2026-26322：Gateway工具SSRF漏洞，CVSS 7.6（高危）
- CVE-2026-26319：Telnyx webhook身份验证缺失，CVSS 7.5（高危）
- 图像工具SSRF漏洞（GHSA-56f2-hvwg-5743）
- 3个有公开利用代码的高危CVE

**价值**：OpenClaw权限高、联网能力强，安全风险是真实存在的。我们部署时要特别注意网络隔离和操作审计，不能让Agent无限制地访问敏感系统。

## 【豆浆学习笔记】

**对团队的价值思考：**

1. **安全是生命线**：OpenClaw权限很大（发消息、读文件、跑脚本），但安全漏洞也真实存在。我们部署时要：
   - 定期更新版本（但不要追最新版）
   - 敏感操作设置人工确认环节
   - 避免让Agent无限制访问关键数据

2. **多Agent协作是方向**：sessions_yield机制的加入，说明OpenClaw在往多智能体协作方向演进。我们可以探索：
   - 把"任务拆解"和"执行"分离
   - 豆浆（主控）→ 子Agent（专业任务）分工模式

3. **治理能力待关注**：EnterpriseClaw的企业级治理思路值得参考，未来我们的招标项目管理可能需要类似的能力——Agent能做事，但关键节点要人类确认。

4. **升级策略建议**：
   - 当前稳定版本：2026.4.23或2026.4.25
   - 2026.4.27仍处于热修期，不建议追
   - 每次升级前先备份配置

5. **国内适配优势**：OpenClaw对飞书、微信等国内平台的支持，以及MiniMax等国内模型的集成，让我们更容易构建自主可控的AI办公助手。
