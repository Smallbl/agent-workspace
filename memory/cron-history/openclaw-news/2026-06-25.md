### ③ 🔐 安全警报：OpenClaw 多平台零日漏洞（已修复）
披露时间：2026年6月8日
安全研究机构 IANS Research 发现 OpenClaw 存在 5 个零日漏洞，允许攻击者通过冒充可信用户来劫持 AI Agent。漏洞最初出现在 Telegram 集成中，迅速扩散至 Slack、Discord、Microsoft Teams 等多个渠道，根源是 OpenClaw 长期依赖用户定义的"白名单机制"来控制 Agent 访问权限，而身份校验逻辑在多平台间存在重复性设计缺陷。
官方已在 v2026.5.x 及后续版本中逐一修复，强制推行 ID 白名单匹配机制。
⚠️ 影响：任何在飞书、Slack 等渠道使用 OpenClaw 的用户都应及时升级到最新版本。
🔗 https://www.iansresearch.com/resources/all-blogs/post/security-blog/2026/06/08/openclaw-zero-days-allow-attackers-to-hijack-agents-across-messaging-platforms
🔗 https://thehackernews.com/2026/06/new-attacks-trick-openclaw-ai-agent.html

### ④ 🚀 OpenClaw v2026.5.28：Agent 运行时全面加固，Provider 能力再扩展
发布时间：2026年5月31日
这是当前机器运行的版本（2026.5.28），主要改进包括：
• Agent/Codex 运行时恢复加固：subagent 的 cwd/workspace 分离、session locks 超时释放、Codex 失败隔离等，多 Agent 场景更稳定；
• 渠道安全全面增强：飞书、Discord、WhatsApp 的认证根和会话身份保护加固；
• 移动端体验提升：iOS 连接稳定性、Apple Watch 审批流程修复；
• PDF 处理升级：支持加密 PDF 提取，MCP 结构化内容可在 Agent 工具结果中呈现；
• Provider 扩展：新增 Claude Opus 4.8、Fal Krea 图像模型、NVIDIA 模型目录、MiniMax 流式音乐响应等。
