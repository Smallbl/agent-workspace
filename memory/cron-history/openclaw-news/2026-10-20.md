## 资讯列表

原文：https://releasebot.io/updates/openclaw

### 2. 3-4月安全硬化包：史上最大安全更新
从3月下旬至4月中旬，OpenClaw 推送了项目历史上最大规模的安全更新：
- 环境变量硬化：阻止恶意工作区注入
- 跨组件信任修复：远程节点事件默认不信任
- WebSocket 会话在 Token 轮换后立即失效
- Skills 路径验证防止目录逃逸

运行在多用户或生产环境的团队必须升级。

原文：https://petronellatech.com/blog/openclaw-ai-agent-guide-2026

### 3. TaskFlow + Providence Memory：生产级 Agent 运行时就绪
OpenClaw 4月的更新从"演示版"进化为"生产级 Agent 运行时"：
- TaskFlow：持久化工作流编排层，支持断点续传
- Providence Memory：带来源标签的记忆系统，可追溯
- 多模型路由：支持运行时切换 GPT-5.5/Claude/Gemini/DeepSeek/Ollama/Gemma

原文：https://www.mindstudio.ai/blog/openclaw-april-2026-update-new-features-agentic-runtime

## 豆浆学习笔记

### 这些更新对王和团队的价值

1. **安全硬化 → 必须重视**
   3-4月的安全更新不是可选项。如果部署在多人使用或暴露在外部网络的环境，这是必修课。

2. **TaskFlow 是工作流的未来**
   飞书消息处理、项目跟踪、多供应商协调——这些正是 TaskFlow 擅长的"持久化状态 + 断点续传"场景。值得研究如何把现有的自动化流程迁移到 TaskFlow。

3. **多模型路由 → 成本优化**
   多模型路由允许用 DeepSeek/Ollama 处理简单分类/路由，用 Claude 做复杂判断，用 GPT 处理实现——这是实打实的成本优化机会。

### 值得尝试的新特性
- 检查版本，如需升级先做备份
- 探索 TaskFlow 文档，看能否改善现有的周期性简报生成
- 评估多模型路由在工作流中的可行性
