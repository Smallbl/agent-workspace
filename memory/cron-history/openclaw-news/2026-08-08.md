# 【OpenClaw日报】📅 2026-08-08

🔖 当前版本：OpenClaw 2026.5.28（最新稳定版：2026.7.1-2，发布于 2026-08-04）

---

## 📌 资讯一：v2026.7.1 正式发布——Control UI 大改版 + 移动端全面升级

7月13日发布的 v2026.7.1 是近两个月最重要的版本，带来了 Control UI（控制界面）的全面重构，覆盖聊天、会话、工作区和用量查看等多个模块。同时 iOS、Android、macOS 三大官方 App 均有重大更新。值得特别关注的是：大中文/日文/韩文工具结果的上下文估算精度提升，减少了误报"上下文溢出"的情况；新增 `openclaw doctor --fix` 可自动迁移旧版 Memory Core 索引，无需全量重嵌入。对我们这类依赖飞书渠道的用户来说，这次更新直接提升了对话的稳定性和可靠性。

原文链接：https://docs.openclaw.ai/releases/2026.7.1

---

## 📌 资讯二：v2026.6.11 重点修复渠道可靠性，Feishu 等多渠道受益

6月30日发布的 v2026.6.11 聚焦于修复影响 OpenClaw 实际使用可靠性的问题——包括回复错位、发送卡住、重新连接失败、模型设置失败等。官方特别提到在 Telegram、WhatsApp、Matrix、Google Chat、飞书（Feishu）和 Mattermost 这六个渠道中，消息被丢弃、重复发送或错误路由的概率大幅降低。另外还新增了 Slack 路由器中继模式（适合多 Gateway 托管部署），以及 Raft External Agent 唤醒桥接功能。对我们这类企业多渠道用户，这些修复直接影响日常使用体验。

原文链接：https://docs.openclaw.ai/zh-CN/releases/2026.6.11

---

## 📌 资讯三：安全警示——OpenClaw 配置和 Token 被 InfoStealer 窃取

网络安全领域传来警报：一种名为 InfoStealer 的恶意软件正在专门窃取 OpenClaw 的 AI Agent 配置文件和 Gateway Token。此类攻击在2月份已有记录，攻击者通过恶意技能（malicious skills）入侵 ClawHub 生态。值得庆幸的是，ClawHub 已与 VirusTotal、ClawScan 达成合作进行技能安全筛查，6月1日还宣布与 NVIDIA 合作加强筛查能力。新加坡网络安全局（CSA）也在5月28日发布了 OpenClaw 安全风险 advisory，提醒企业部署前做好安全评估。我们使用飞书渠道尤其需要注意：不要随意安装来源不明的技能，定期检查 `openclaw doctor` 的安全警告。

原文链接：https://thehackernews.com/2026/02/infostealer-steals-openclaw-ai-agent.html
新加坡CSA Advisory：https://www.csa.gov.sg/alerts-and-advisories/advisories/ad-2026-005

## 📌 资讯四：ClawHub 安全生态进展——NVIDIA 加入筛查合作

Palo Alto Unit 42 在6月23日发布研究报告，揭示了2月至5月期间 ClawHub 上恶意技能的逃避性 campaign，尽管 VirusTotal/ClawScan 已集成，仍发现5个未被阻止的恶意技能。这一研究推动了 ClawHub 在6月1日与 NVIDIA 建立合作关系，进一步强化技能发布前的代码级分析能力。对我们来说，这意味着从官方渠道安装技能会越来越安全，但仍应保持警惕，避免手动安装来路不明的技能。

原文链接：https://unit42.paloaltonetworks.com/openclaw-ai-supply-chain-risk

---

## 📌 资讯五：OpenClaw 艰难时期回顾与 LTS 路线图预告

OpenClaw 官方博客坦承，2026.4.24 到 2026.4.29 那段时间是"艰难的一周"——Gateway 性能下降、部分安装陷入插件依赖修复循环、Discord/Telegram/WhatsApp 等渠道表现异常。官方承诺：未来 OpenClaw 会变得更精简，把可选功能转移到 ClawHub；同时宣布将在5月晚些时候单独公布 LTS（长期支持版）计划。这意味着未来可能会有更稳定的企业级版本值得期待，也提示我们在生产环境中应谨慎追最新版，优先参考官方 LTS 建议。

原文链接：https://openclaw.ai/blog/openclaw-rough-week

## 【豆浆学习笔记】

### 📊 对我们团队的价值分析

#### 1. 渠道稳定性是核心
- v2026.6.11 和 v2026.7.1 连续两个版本都在修复渠道可靠性，特别是飞书（Feishu）渠道的消息丢失、回复错位问题
- 这直接关系到日常使用体验，建议尽快升级到 v2026.7.1-2（最新补丁版）

#### 2. 安全风险不容忽视
- InfoStealer 和 ClawHub 恶意技能事件提醒我们：安装技能前务必确认来源
- 重要项目不要追 beta 版本
- 定期运行 `openclaw doctor` 检查安全配置

#### 3. 值得尝试的新功能
- **Cron 任务"条件触发"**：可在外部命令完成或状态变化时才唤醒 agent，适合监控脚本场景
- **`openclaw doctor --fix` 自动修复 + 索引迁移**：升级前建议跑一遍，避免历史记忆丢失
- **Android 端安全页面缩略图预览**：移动端体验改善

#### 4. 生产环境建议
- 不要在生产环境追 beta
- 关注即将发布的 LTS 版本（官方预告5月后公布，目前8月应该已有详情）
- 多渠道备份重要对话和记忆文件
