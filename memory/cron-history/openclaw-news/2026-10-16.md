## 📌 一、OpenClaw 2026.10.3 正式发布（10月13日）

最新稳定版 2026.10.3 于10月13日发布，修复了升级过程中被阻塞的问题，改进了 Mac 应用设置，并防止对话在压缩或中断的供应商回复后失败。特别值得注意的是：之前版本中遗留的更新恢复记录和旧版更新记录现在可以被清理，2026.9.8 中断的更新也能被正确处理。Anthropic 提示缓存现在可以跨会话保持一致，避免了之前 follow-up 时缓存失效的问题。

原文：https://www.betterclaw.io/blog/openclaw-latest-version

## 📌 二、OpenClaw 2026.10.4 紧急补丁（10月16日）

就在今天（10月16日），OpenClaw 发布了 2026.10.4，这是一个自描述为 2026.10.3 稳定补丁的小版本，没有新功能或配置变更。根据独立追踪平台 ClawStat.us 的评估，目前没有发现可信的阻塞问题，但因发布时间太短（仅数小时），仍建议谨慎对待。对普通用户而言，当前进階稳定版（LTS）推荐使用 2026.9.9，已在生产环境运行8天。

OpenClaw 2.0（v2026.8.1，8月31日发布）是今年最大的更新版本，合并了 16,977 个 pull request，有 987 位贡献者参与。新功能包括：重新构建的 Web 界面、更简单的 onboarding 流程（能自动检测现有的 AI keys 和本地模型）、对话搜索功能，以及可以在配对设备或云端 worker 上运行的会话功能。这个版本奠定了当前架构的基础。

## 【豆浆学习笔记】

### 🔍 这些更新对我们团队的价值分析：

**1. 升级体验大幅改善**
2026.10.3/10.4 系列重点修复了升级过程中的阻塞和回滚问题。过去升级失败是个痛点，现在 Doctor 工具可以清理遗留的更新状态。这意味着我们可以更放心地跟进最新版本，不用担心升级失败导致服务中断。

**2. Anthropic 缓存一致性**
`claude-3-5-sonnet` 等模型的提示缓存现在跨 follow-up、重启和子 agent 完成都能保持字节一致。这对需要长时间多轮对话的场景（比如复杂项目分析）有实际帮助——缓存命中率高，响应更快且成本更低。

**3. 对话稳定性**
压缩和中断回复的处理改进，减少了对话中途失败的概率。对于我们通过飞书与 OpenClaw 交互的场景，这个改进直接提升了使用体验。

**4. 要不要升级到 2026.10.3/10.4？**
当前运行的是 2026.9.5，属于较新版本。ClawStat.us 建议普通用户如果当前版本稳定可以"按兵不动"，但如果要尝鲜新版本，10.4 目前看起来没有重大阻塞问题。

**5. 关注点**
有用户反馈 Gateway 更新时间从 ~3分钟 增加到 ~45分钟（2026.9.3 → 2026.10.2），这是值得关注的性能回归。
