## 📦 1. OpenClaw v2026.9.5 正式发布（最新版本）

**发布时间：** 2026年9月19日

OpenClaw 发布了 v2026.9.5，这是目前最新的稳定版本，包含多项重要新特性：

- **⚛️ 原子化更新（Atomic Updates）**：更新机制更加安全，失败时可以回滚到之前状态，不会破坏现有配置
- **🔥 插件热重载（Plugin Hot Reload）**：插件无需重启 Gateway 即可生效，开发和调试更高效
- **🤝 对话分享（Conversation Sharing）**：可以将对话分享给其他用户或团队成员
- **🎙️ 扩展 GPT Live**：支持更多实时语音交互场景
- **🌐 共享浏览器页面**：多人可以同时查看和操作同一个浏览器页面
- **📦 对话归档（Conversation Archiving）**：支持将重要对话归档保存
- **🧠 专家型 Agent 配置（Specialist-agent setup）**：可以配置专注特定领域的子 Agent

该版本由 4,179 个 PR、502 位贡献者完成。

## 🔐 2. OpenClaw 2.0 正式发布：凭据隔离成为核心亮点

**发布时间：** 2026年8月31日（v2026.8.1）

OpenClaw 2.0 是自 2024 年发布以来最大的一次更新，包含超过 16,000 个 PR，由 933 位贡献者完成。主要变化：

- **凭据隔离（Credential Isolation）**：Agent 可以通过"掩码提示"请求密钥，实际值永远不会进入对话记录或模型上下文，从根本上防止凭据泄露
- **可选代理限制**：可以将凭据绑定到特定目标主机，例如公司 Slack 工作区的凭据永远无法发送到未经授权的域名
- **团队级密钥库（Secret Store）**：面向共享部署，支持多用户场景下的安全凭据管理
- **主动记忆（Active Memory）** 和 ** grounded dreaming**：增强长期记忆和推理能力

⚠️ 安全背景：2026 年安全研究显示，OpenClaw 社区技能中有 7.1% 存在高危漏洞，超过 30,000 个实例直接暴露在公网，2.0 的凭据隔离是针对性的回应。

🔗 https://tech-insider.org/openclaw-2-0-release-credential-security-2026

## 📊 3. v2026.9.1：Mermaid 图表、内存优化、更新安全增强

**发布时间：** 2026年9月初

v2026.9.1 是一个重要的维护版本，带来多项实用改进：

- **Mermaid 图表渲染**：在 Control UI、Android、iPhone、iPad 和 Mac 的对话中直接渲染 Mermaid 图表，技术文档和流程图更直观
- **工作树管理改进**：可以将工作树放在其他磁盘或文件夹，不影响 OpenClaw 主状态；共享 checkout 目标从 100 提升到不受限制（由磁盘空间决定）
- **更新安全保障**：更新前更清晰地区分"可以安全完成的工作"和"需要你先处理的工作"；更新失败时保留上下文，可交给 Doctor 或编码 Agent 调查
- **性能优化**：降低内存占用，减少重复工作，特别是在处理长对话和大安装时效果明显

## 📝 【豆浆学习笔记】

### 🔍 这些更新对我们的价值分析

**1. 凭据隔离（最值得关注）**
- 我们的飞书、Bitable 等都涉及 API 凭据，虽然目前是本地运行风险较低，但这个功能可以进一步提升安全等级
- **可以尝试**：等我们升级到 2.0 后，在配置敏感凭据时启用这个选项

**2. 插件热重载**
- 非常实用！之前改一个 skill 或插件需要重启整个 Gateway，现在不用了
- **可以直接用**：以后调试自定义 skill 时效率会明显提升

**3. 对话归档**
- 对于我们记录项目跟进、系统维护日志很有用
- **可以尝试**：把重要的系统变更记录归档，方便以后审计

**4. 专家型 Agent 配置**
- 这可能是多 Agent 协作的进一步发展
- **观望**：等稳定后可以考虑为不同业务线配置专门的 Agent

**5. Linux 桌面版**
- 我们目前用的是 macOS，但如果有 Linux 服务器部署需求，这个很有用

### 📋 升级建议

当前版本 2026.6.34，落后于最新版本 2026.9.5。建议：
- 观察 2-3 周，等 2.0 的早期问题修复后再升级
- 升级前先跑 `openclaw doctor` 检查配置兼容性
- 特别注意：2.0 有配置迁移，需要运行 `openclaw doctor --fix`
