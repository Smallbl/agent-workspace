## 📰 OpenClaw 最新资讯（2026年9月）

### ① 【重磅】OpenClaw 2026.9.6 发布 — 新模型支持、30天用量报告、GitHub集成

2026.9.6 版本带来了大量实用更新：新增 Claude Opus 5.5、GPT-6 Sol/Luna、Grok 4.7 模型支持；完整的30天用量报告让用户清楚掌握消耗情况；内置 GitHub Reader 可在对话中直接查看公开讨论和代码 Diff；远程工作区支持文件、记忆和技能同步；会议笔记支持实时捕获更新。此外还修复了 Code Mode 验证漏洞（OpenAI 访客运行绕过了验证检查）和 macOS 应用启动崩溃问题。共有 2,614 个 PR、178 次提交、350 位贡献者参与。

原文链接：https://docs.openclaw.ai/releases/2026.9.6

---

### ② 【里程碑】OpenClaw 2026.8.1 被称为"OpenClaw 2.0"，史上最大更新

8月发布的 2026.8.1（代号 OpenClaw 2.0）是一次全面重构，涵盖安装、消息、记忆、技能、模型、自动化、浏览器/原生应用、插件、安全等所有层面。引入了新的 Control UI 将对话置于核心位置，Sessions 和 Transcripts 迁移至 SQLite 存储，Skills 工作流统一为从创建到安装调用的完整路径，原生应用（iOS/Android/macOS/Wear OS）全面升级。共有 16,977 个 PR、698 次提交、987 位贡献者参与。

原文链接：https://docs.openclaw.ai/releases/2026.8.1

---

### ③ 【安全】Code Mode 验证漏洞修复 — 强化编译和变更工具检查

OpenClaw 修复了 Code Mode 验证中的一个关键漏洞：OpenAI 访客运行时切换了终端证据检查方式，封堵了之前允许某些分支跳过验证的缺口。同时强化了 compaction 和变更工具的检查逻辑。

原文链接：https://releasebot.io/updates/openclaw

---

### ④ 【合作】微软 Autopilot 宣布基于 OpenClaw 构建，双方贡献双向共建

OpenClaw 官方博客报道，微软在 2026 年 9 月宣布其 Autopilot（始终在线的 AI Agent）基于 OpenClaw 构建。微软团队已向 OpenClaw 回馈了大量代码贡献。这一合作表明 OpenClaw 已进入企业级基础设施领域。

原文链接：https://x.com/openclaw

---

### ⑤ 【插件生态】OpenClaw 插件热加载功能上线

OpenClaw 核心团队发布了插件热加载（Hot Reloading）功能，允许在不重启 Gateway 的情况下动态更新插件。注意：`sessionFork` 将于 2026年10月12日 停用，插件作者需迁移至 sessionForkV2。

原文链接：https://x.com/openclaw
