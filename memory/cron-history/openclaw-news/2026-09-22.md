## 📌 一、OpenClaw 2026.9.5 发布——团队创建与技能库全面升级

这是9月以来最重要的版本。新增"引导式团队创建"功能，可以一键生成四种专业角色团队（首席顾问、研究员、写作官、审核官），或者创建单一专业角色。实验性"房间团队"功能允许多个Agent在同一个对话中协作，每个专家可以针对性响应，支持 Discord/Slack 中的多Agent讨论。此外，Skill Workshop（技能工坊）升级为跨工作区持久化存储，技能可完整对比、支持ZIP导入和团队网关分享。

👉 https://releasebot.io/updates/openclaw

## 📌 二、OpenClaw 2026.9.4——稳定构建全面验证

该版本在 npm、Docker、macOS 和 Linux 桌面包上完成校验签名和校验和验证，正式推出实时稳定更新推送通道。这意味着用户可以通过 `openclaw update` 安全地获取经过完整性验证的正式版，降低了更新导致系统中断的风险。

👉 https://releasebot.io/updates/openclaw

## 📌 三、OpenClaw 2.0（2026.9.2）——原子化更新，不再怕升级失败

这是9月初最受好评的更新，被称为"第一个无缝升级的版本"。核心改进：
- 更新时保持现有 Gateway 持续运行
- 更新失败自动回滚到上一版正常配置
- 始终保留一个可用的工作 Agent，以便诊断故障原因
- 新增一键问题报告按钮

用户反馈"第一次 Agent 主导的更新完美运行"，Discord 工具调用恢复、响应速度明显提升。

👉 https://openclaw.ai/blog/shipping-openclaw-updates-that-dont-break

## 📌 四、OpenClaw 2026.9.1——稳定与可读性改进

这是一个"稳定性和打磨"版本，不追求新功能，专注于让现有功能更可靠：
- Mermaid 流程图现在可以在 Control UI、iOS/Android 原生应用中直接渲染，带放大预览和移动端重试
- 新安装用户获得快速入门引导，自动检测现有 Claude Code 或 Codex 登录状态
- 个人技能库可与工作区技能库分开管理
- 更强的更新恢复机制：失败后保留配置、自动回滚

👉 https://docs.openclaw.ai/releases

## 📌 五、安全与性能：2026.6.34 内核加固

当前运行版本 2026.6.34 的亮点是浏览器沙箱和网络边界加固：
- 沙箱化浏览器路由
- 可信 DNS 目标限制
- 自定义浏览器来源验证
- Loopback 端点拒绝非安全访问路径

这个版本解决了跨域重定向中 Secret 泄露问题，并加强对 Java/Rust/Git/Kubernetes 等环境变量的恶意覆盖防护。

👉 https://patchbot.io/ai/openclaw

## 【豆浆学习笔记】

### 🔍 这些更新对王和我的意义：

1. **原子更新（2.0）最值得升级**：之前不敢频繁更新是因为怕升级失败导致服务中断。原子更新 + 自动回滚意味着我可以更主动地保持版本最新，不用担心"更新翻车"。建议王考虑升级到 2026.9.5。

2. **多Agent团队协作值得探索**：2026.9.5 的"房间团队"功能如果成熟，可以让不同的专业Agent（研究、写作、审核）协同处理复杂任务，比如项目文档的多角色审查流程。

3. **技能库升级对知识管理有直接价值**：Skill Workshop 跨工作区持久化 + 可完整对比，意味着我可以为王建立更结构化的技能集合，比如针对"招投标行业"的专项技能模板。

4. **安全加固持续关注**：作为企业级应用，特别是处理飞书消息和文档访问，安全边界加固是必要的。特别是跨域重定向防护和敏感信息脱敏，对保护业务数据有实际意义。

5. **版本节奏非常快**：从版本号看，OpenClaw 在以每周多个版本的速度迭代。要保持竞争力，建议每个月至少关注一次 release notes。
