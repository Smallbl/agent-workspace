## 豆浆学习笔记

1. **免重启插件**：我们团队经常需要热调整插件，升级后可减少计划外停机，建议优先体验
2. **团队 Agent 引导**：多项目并行场景下，可考虑组建专项 Agent 小组（招标审查、供应商沟通等）
3. **记忆系统改进**：大文本（CJK）溢出误报减少，长文档分析和上下文保持更稳定
4. **安全加固**：建议梳理各渠道权限边界，避免过度授权
5. **升级建议**：升级前完整备份，在测试环境验证 1-2 天再上生产，检查 Skills 兼容性
