## 1. 【安全警报】CVE-2026-62225 漏洞影响所有 v2026.5.18 以下版本

OpenClaw 官方确认存在一个 Skill 命令调度缺陷漏洞（CVE-2026-62225），影响 v2026.5.18 以下所有版本。
该漏洞属于 Skill 命令调度层面问题，攻击者可能借此执行未授权操作。
👉 豆浆当前版本为 v2026.5.28，不受此漏洞影响，但建议持续关注更新。

原文：https://www.bighatgroup.com/blog/openclaw-weekly-2026-07-20

## 2. ⚠️ v2026.7.1 稳定性危机：建议生产环境暂缓升级

v2026.7.1 于 7 月 13 日晋升稳定版，带来了大量新功能（Control UI 大改版、GPT-5.6 支持、移动端 App 全面更新等），
但同时存在 Gateway 崩溃循环问题，稳定性不达标。
官方建议：生产环境使用 extended-stable 频道，或暂时锁定在 v2026.6.11。
v2026.7.2 beta 已在测试中，远程编码会话架构是重点方向。

原文：https://www.bighatgroup.com/blog/openclaw-weekly-2026-07-20

## 3. v2026.7.1 正式版核心功能一览（7月13日发布）

- **Control UI 大改版**：支持对话并排显示、实时任务追踪、引导式入门教程
- **模型支持扩展**：GPT-5.6 全面支持，新增腾讯混元（Tencent Hy3）、Meta Muse Spark 1.1、Claude Sonnet 5、ClawRouter
- **官方 App 全面更新**：iOS、Android、macOS 三大平台在设置、导航、聊天、语音、文件、定时任务等方面均有重大改进
- **Codex 深度集成**：`openclaw attach` 可对接外部编码 Agent，支持临时可撤回凭证
- **Telegram/Slack/Discord/Apple Messages** 均有重要工程更新

原文：https://docs.openclaw.ai/releases/2026.7.1

## 4. v2026.3.22 大升级回顾：插件架构彻底重构（3月24日）

这是 OpenClaw 史上最大架构升级之一，核心变化：
- 旧插件 API（openclaw/extension-api）被完全移除，一刀切无过渡
- 全新的 openclaw/plugin-sdk/* 模块化接口正式登场
- **ClawHub 成为插件分发首选渠道**（取代此前的 npm 直装）
- **安全大修**：封堵 Windows SMB 凭证泄露、环境变量注入、Unicode 审批伪装等十余个漏洞
- **模型升级**：GPT-5.4 上位，MiniMax 统一为单一插件（API + OAuth 入口合并）
- **Anthropic Vertex 正式接入**，可通过 Google Vertex AI 调用 Claude 模型

原文：https://finance.sina.com.cn/tech/digi/2026-03-24/doc-inhrzumc3562989.shtml

## 🧠 豆浆学习笔记

### 1. 安全永远是第一位的
CVE-2026-62225 漏洞提醒我们，即使是热门开源项目也可能存在 Skill 命令调度层面的风险。
好在豆浆目前运行在 v2026.5.28，已经在该漏洞修复版本之后。
✅ **行动项**：定期执行 `openclaw doctor` 检查健康状态，保持在安全版本线。

### 2. 升级策略：稳字当头
v2026.7.1 的稳定性危机说明，即使是"stable"标签的版本也需要观察。
对于豆浆这种需要 7×24 小时运行的 Agent 系统，生产环境不能盲目追新。
📌 **建议**：继续使用当前 v2026.5.28，等待 v2026.7.2 稳定版发布并确认无重大 bug 后再升级。

### 3. 插件生态变化值得关注
v3.22 的插件 SDK 重构是一把双刃剑——新 API 更安全规范，但旧插件需要迁移。
ClawHub 成为官方首选分发渠道，说明 OpenClaw 正在建立更封闭但更可控的生态体系。
🤔 **思考**：我们的飞书、天气等插件是否需要重新评估来源和安全性？

### 4. 远程编码会话（v2026.7.2 beta）值得期待
分布式 Agent 执行架构意味着未来豆浆可能可以调度其他机器上的子 Agent 完成任务。
这对多设备协作（Mac mini + 办公电脑）场景非常有价值。
👀 **关注**：v2026.7.2 正式发布后第一时间评估。

### 5. AI Agent 元年已来，我们走在正确的路上
Peter 说"如果不需要完美质量，AI 可以做更多更快更便宜"——这非常符合我们的实际情况。
招标代理行业的日常：信息收集、文件整理、会议纪要、进度跟踪——这些恰恰是 Agent 最擅长的事。
💡 **愿景**：豆浆不只是工具，而是真正能帮王分担重复工作的数字同事。
