## 📰 OpenClaw 动态简报

### ① 【安全升级】ClawHub 全面引入 NVIDIA SkillSpector 扫描，每款 Skill 都配有"技能卡"

**2026年6月1日**，OpenClaw 宣布与 NVIDIA 合作，为 ClawHub 上的每一款 Skill 生成"Skill Card"（技能卡）。

技能卡记录该 Skill 的来源、用途和 ClawScan 的扫描结论，由 ClawHub 官方验证而非发布者自述。同时所有 Skills 都要经过三重扫描：内部静态分析、VirusTotal、NVIDIA SkillSpector（检测隐藏指令和代理风险），最终给出 Clean / Suspicious / Malicious 判定。NVIDIA 还把 ClawScan 扫描结果数据集（覆盖 67,453 个 Skill 版本）公开上传至 Hugging Face。

**→ 价值：** 我们的工作流大量依赖 ClawHub 上的 Skill，这个机制意味着以后安装 Skill 时有据可查的安全背书，不用再担心 Skill 里藏恶意代码。

🔗 https://openclaw.ai/blog/openclaw-nvidia-skill-security

### ② 【性能大幅提升】安装包体积缩小 53%，冷启动从 9.8 秒降至 1.9 秒

**2026年5月28日**官方博客披露了代号"Lighter Core, Sharper Claws"的性能优化成果：对比 v2026.4.14，v2026.5.28 的冷启动时间从 9.8 秒压缩到 1.9 秒（下降 81%）；npm 包体积缩小 53%；本地安装后 node_modules 从 686 MB 减少到 581 MB。核心策略是把 Bedrock、Slack、OpenShell、Anthropic Vertex、Matrix、WhatsApp 等可选能力移出核心依赖，走插件路线。

**→ 价值：** 我们的 Mac Mini 上跑 OpenClaw，安装更小、启动更快，意味着后台常驻的体验更流畅。

🔗 https://openclaw.ai/blog/lighter-core-sharper-claws

### ④ 【2026.7.1 Beta】Session Goals 持久化 + GPT-5.6 支持 + openclaw attach 新命令

2026年7月2日发布的 2026.7.1-beta.1（7月5日更新至 beta.2）带来几个值得关注的预览特性：

- **Session Goals 持久化**：长期运行的 agent 可以在 per-turn 上下文中记住当前任务目标，不再依赖脆弱的 transcript 记忆

- **openclaw attach**：支持外部 harness 附加到 OpenClaw
- **Telegram Codex** 登录和引导流程

**→ 价值：** Session Goals 持久化对长期多步骤任务（如项目跟踪、招标流程监控）意义重大，值得在 beta 稳定后第一时间尝鲜。

### ⑤ 【安全加固】插件安装默认 fail-closed，busybox/toybox 移出安全列表

2026年4-5月间完成的安全加固：

- 插件安装现在默认 **fail-closed**——未经验证的插件必须加 `--dangerously-force-unsafe-install` 参数才能绕过
- 远程节点事件默认标记为 **untrusted** 并在到达主 agent 前做消毒处理
- Token 或密码轮换后 **WebSocket session 立即失效**
- Skill 文件做 **realpath()** 校验防止目录穿越
- **busybox 和 toybox** 从安全工具列表中移除（任何调用它们的 Skill/工具会报错）

**→ 价值：** 这个变化对有自动化安装脚本的团队有影响，需要检查现有脚本是否依赖旧的安装行为。对我们的安全运营来说，默认 fail-closed 是正确的方向。

🔗 https://petronellatech.com/blog/openclaw-ai-agent-guide-2026

## 💡 【豆浆学习笔记】

**这次读下来，我最关注三个方向：**

**1. Skill 安全机制对我们最有直接价值**
ClawHub Skill Card + NVIDIA SkillSpector 意味着以后在安装 Skill 前可以先看它的安全报告，而不是盲目信任。建议梳理一下我们目前装了哪些 ClawHub Skill，记录它们的版本和来源，作为资产清单管理起来。

**2. Session Goals 持久化是长期任务的救命特性**
我们经常让 agent 做多步骤项目跟踪，之前遇到的问题是 session 断了就丢失上下文。如果 Session Goals 能持久化，结合 Cron 做定期唤醒，就能真正实现"后台数字员工"的效果——不用人盯着，任务自己跑下去。

**3. 留意 2026.7.1 稳定后的升级窗口**
beta.2 才刚出（7月5日），预计 7 月内会有稳定版。届时建议先在非生产环境验证 Telegram 渠道和 Session Goals 表现，再推正式环境。

**一个待办：** 建议王确认一下我们目前 OpenClaw 版本 2026.5.28 距最新稳定版 2026.6.11 差距两个小版本，是否需要升级。升级前记得快照。
