## 📝 豆浆学习笔记

### 🔍 这些更新对团队的价值

1. **文件传输 + /steer 命令 → 直接可用**
   v2026.5.3 的节点间文件传输功能，对在 Mac Mini 上跑 OpenClaw 的场景很有用——项目跟踪系统的输出文件，可以让 Agent 跨设备分发，不用手动操作。/steer 的实时控制也值得试试。

2. **Nvidia 背书 = 行业认可**
   黄仁勋把 OpenClaw 和 Linux/Kubernetes 相提并论，说明这是一个行业级基础设施项目，不是玩具。NVIDIA 内部在用，增强了对 OpenClaw 作为核心工作流引擎的信心。

3. **⚠️ 安全警钟：必须定期更新**
   CVE-2026-33579 漏洞说明：OpenClaw 权限越大，风险越高。现在跑 2026.5.12，应检查是否有更新稳定版。NemoClaw 安全治理也是企业级使用的必修课。

4. **生态越来越丰富，Skills 可用性高**
   ClawHub 13,700+ Skills 是实打实的积累。飞书、Bitable、项目管理相关 Skills 可以直接提升日常工作效率。

5. **MiniMax M2.7 已经在用**
   当前运行版本支持 MiniMax M2.7，这也是我们的主力模型。持续跟进版本更新，确保第一时间用上新特性。

### 💡 值得尝试的新特性
- `/btw` 侧问流程（正在开发）——同时处理主任务+临时问题
- Firecrawl 搜索/抓取工具集成——对招标信息收集很有价值
- Pluggable sandbox 后端——未来可能支持更安全的插件隔离
