## 📰 最新资讯

### 1️⃣ OpenClaw v2026.5.18 发布：认证修复与稳定性提升

**概要：** OpenClaw 5.18 版本是一个以稳定性为核心的大版本，主要修复了多项认证问题和系统稳定性。包含了 xAI/Grok OAuth 认证修复、Android 实时语音对话模式、Telegram 媒体和论坛主题投递修复、浏览器对话框可见性改进（现在可以正确回答弹窗）、Agent 修复默认采用干净的受限重构方式、Node.js 最低要求提升至 22.19 版本、以及 Docker/Podman 改进和 Gateway/ACPX 启动追踪功能。

**重要性：** 这个版本让 Gateway 重启速度更快（并行启动 + 重启追踪，VPS 用户特别受益），浏览器自动化能力得到显著改善，原生集成 Obsidian CLI 让"网页研究→笔记"流程更顺畅。对我们日常使用来说，这意味着飞书/Telegram 的稳定性会更高，浏览器操作更可靠。

### 2️⃣ OpenClaw v2026.4.29：24 项更新 + 312 个修复，智能化大幅提升

**概要：** 这是 2026 年规模最大的版本之一。消息和自动化更加智能：主动运行操控现在默认启用，可视回复强制执行。Memory Wiki 现在支持"人物感知"功能，能理解是谁在提问、谁的影响最大。多 Agent 心跳调度修复了 7 层问题（并行广播、受限跳过、HEARTBEAT.md 指令始终附加等），大幅提升了多 Agent 并行运行的稳定性。

**重要性：** 对我们这种多 Agent 架构来说，心跳调度的修复非常重要——之前一个子 Agent 卡住会影响其他 Agent，现在完全隔离了。Memory 的人物感知对王这样需要跟进多个项目、多个供应商的人来说，可以让 Agent 更精准地理解上下文。

🔗 https://x.com/iamlukethedev/status/2049992708262174922

### 3️⃣ ClawHub 技能市场成为默认包源 + Plugin SDK 全面重构

**概要：** 自 v2026.3.22 起，ClawHub 已成为默认包源，全新的 Plugin SDK 正式启用。新技能包括：`openclaw skills search|install|update` 可直接浏览和安装 ClawHub 上的技能、Claude marketplace registry（直接通过 plugin@marketplace 安装 Claude 捆绑包）、Codex/Claude/Cursor 捆绑包发现（兼容捆绑包自动映射为 OpenClaw 技能）、Owner 限定的 /plugins 聊天命令（直接在聊天中管理插件）。Matrix 插件完全重写，遗留环境变量已移除。

**重要性：** 技能市场的成熟意味着我们可以更方便地扩展 Agent 能力——不需要自己写代码，直接从市场安装即可。对于我们这种"Coordinator + 专业子 Agent"的架构，每个子 Agent 可以按需安装专业技能。

### 4️⃣ Anthropic 调整 Claude 订阅政策：OpenClaw 用户需转向按量付费

**概要：** 2026 年 4 月，Anthropic 宣布 Claude 订阅用户不再能通过订阅额度使用 OpenClaw 等第三方工具，转为按量计费模式。这对运行持续 Agent 工作流的用户来说，成本明显增加，部分开发者不得不重新配置基础设施。OpenClaw 创始人 Peter Steinberger 认为这是行业调整的体现——Agent 系统比传统聊天消耗资源多得多，AI 提供商正在调整定价和访问模式来应对。

**重要性：** 作为 OpenClaw 深度用户，我们需要关注 API 成本。考虑使用 MiniMax M2.7（已集成，性价比高）或其他国内模型来降低成本。同时这也是个提醒：不要过度依赖单一模型供应商。

🔗 https://blog.mean.ceo/openclaw-news-april-2026

### 对我们工作的价值

| 更新 | 可应用场景 |

### 值得尝试的新功能

1. **Obsidian CLI 集成**：如果王需要做项目研究，可以让 Agent 自动将网页内容整理到 Obsidian 笔记库
2. **Skills CLI**：`openclaw skills install` 可以快速添加新能力，比如 `meme-maker` 已经在 Skill 市场
3. **心跳主动性**：现在 HEARTBEAT.md 指令会始终附加给模型，可以更好地通过心跳文件引导子 Agent 行为
4. **多 Agent 并行**：之前心跳调度有 bug，现在修复了，可以更放心地让多个子 Agent 同时工作

### 风险提示

- Anthropic 订阅政策变化提醒我们：**监控 API 成本**，不要把所有鸡蛋放一个篮子
- OpenClaw 安全问题（如恶意 Skill 数据窃取）需要警惕：**不要安装来源不明的插件**
- Agent 系统比传统聊天消耗资源多，**需要持续关注服务器性能**

### 下一步行动建议

1. 升级到最新版本（如果还没升级的话）`npm install -g openclaw@latest`
2. 探索 ClawHub 上的实用技能，比如搜索 "feishu" 相关的技能
3. 考虑使用 MiniMax 作为主力模型（成本更低，国内访问更稳定）
4. 定期运行 `openclaw doctor` 检查系统健康状态
