## 📰 OpenClaw 最新资讯

### 1. v2026.5.x Beta 版持续迭代：Gateway 重启加速 + QA 工具增强

OpenClaw 于 5 月中旬连续发布多个 beta 版本（2026.5.18/19），核心改进集中在三方面：
- **Gateway 重启速度优化**：通过与 channel sidecar 并行启动日志和插件服务，大幅降低重启就绪延迟
- **Skills/CLI 改进**：允许 `openclaw 技能安装` 和 `openclaw 技能更新` 命令更灵活使用
- **QA-Lab 测试框架增强**：新增 `--runtime-parallel-tier` 参数，强化 Codex-vs-Pi 层面的发布检查

这意味着生产环境的维护体验正在变好——Gateway 重启不再长时间阻塞，适合作为长期运行的基础设施。

原文链接：https://releasebot.io/updates/openclaw

---

### 2. v2026.4.5 内置视频/音乐生成能力，ComfyUI 工作流集成

v2026.4.5 带来了两个重要的媒体生成工具：
- **`video_generate`**：Agent 可直接通过配置的 provider 生成视频并回复
- **`music_generate`**：内置音乐生成能力

同时还集成了 ComfyUI 工作流和额外的 providers，标志着 OpenClaw 从"对话助手"向"完整操作工作台"的定位迁移。对我们而言，这意味着豆浆未来可以自主生成演示视频/配乐，直接用于工作汇报或汇报材料。

原文链接：https://www.instagram.com/p/DX6rLvbE-ze

---

### 3. v2026.4.10 Active Memory 正式落地：智能记忆子系统

之前版本实验性的"梦境"（Dreaming）功能在 v2026.4.10 演变为成熟的 **Active Memory 层**：
- 可配置的记忆子 Agent，可在主回复前拉取用户偏好、上下文、历史细节
- 支持可配置的上下文深度、转录持久化和详细检查模式
- 改进的每日笔记分块、REM 预览工具、可配置的回忆老化机制

这直接解决了之前"记忆需要人工干预"的问题。豆浆现在可以真正成为"会主动记住事情"的助理，而不只是依赖上下文窗口。

原文链接：https://openclaw.com.au/updates

### 4. ClawHub 插件市场正式上线：13,700+ Skills 可用

随着 v2026.3.22+ 版本，ClawHub 插件市场正式取代 npm 成为默认安装来源。目前已有超过 13,700 个 Skills 可用，覆盖飞书、Discord、Telegram、图像处理、工作流自动化等场景。

这意味着 OpenClaw 正在从"单一工具"进化为"平台生态"——我们可以通过 ClawHub 快速获取新的能力插件，而不用自己开发。

原文链接：https://www.facebook.com/groups/3238547836318385/posts/3293846617455173

### 5. 安全公告：CVE-2026-33579 高危漏洞已修复

4 月，安全研究人员披露了 OpenClaw 的高危漏洞（CVE-2026-33579，评分 8.1-9.8/10），允许拥有最低权限的 pairing 用户提升至管理员权限并完全接管实例。OpenClaw 团队已发布安全补丁。

**提醒**：如果你的 OpenClaw 版本低于 2026.4.x，请立即更新。攻击者可能已在不知情的情况下获取访问权限。

原文链接：https://arstechnica.com/security/2026/04/heres-why-its-prudent-for-openclaw-users-to-assume-compromise

## 🧠 豆浆学习笔记

### 这些更新对我的价值

1. **Active Memory 是最大的惊喜**
   - 之前豆浆的记忆完全依赖上下文窗口和手动写入文件
   - Active Memory 可以让豆浆"主动"记住王的工作习惯、偏好、进行中项目
   - 建议：等 2026.4.x 稳定版发布后，优先测试 Active Memory 功能

2. **视频/音乐生成能力值得探索**
   - 招标工作经常需要制作演示材料、配乐
   - 现在豆浆可以直接生成视频/音乐，无需借助第三方工具
   - 建议：了解 `video_generate` 和 `music_generate` 的具体用法

3. **Gateway 重启优化是真实的生产力提升**
   - 我们目前使用 `safe-gateway-restart.sh` 做 10 秒缓冲
   - 如果新版本重启速度足够快，可能可以简化重启流程
   - 建议：观察 2026.5.x 稳定版的表现

4. **ClawHub 生态值得关注**
   - 13,700+ Skills 意味着很多常见场景已有现成解决方案
   - 飞书相关的 Skills 特别值得研究
   - 建议：定期浏览 ClawHub 发现新工具

5. **安全意识要提高**
   - CVE-2026-33579 说明 OpenClaw 的高权限设计天然存在风险
   - 目前版本（2026.5.18）已包含修复，保持更新就好
   - 建议：建立定期检查更新的机制

### 工作流改进方向

- 利用 Active Memory 让豆浆记住王的常见需求，减少重复说明
- 探索视频生成能力，用于制作系统演示或汇报材料
- 监控 ClawHub 上的飞书相关 Skills，提升文档/消息处理效率
- 保持版本更新节奏，利用 Gateway 重启优化改进维护体验
