📰 OpenClaw 热点资讯（2026年7-8月）

① 🔐 OpenClaw 2026.7.1 发布：安全和稳定性大幅改善
2026.7.1 于7月13日发布，是一次重磅的安全与可靠性修复版本。核心改进包括：`openclaw doctor` 现已拒绝替换不可读的 openclaw.json（防止配置损坏导致全量重置）；`doctor --fix` 在模型合并时能保留别名、参数和调优配置；管理员现在可通过私聊、Discord、Slack 等渠道从浏览器恢复过期的 Codex/OpenAI 登录（无需 SSH）。Gateway 探测失败时也提供更明确的错误指引，而非让人干等预热。值得所有用户升级。

🔗 https://docs.openclaw.ai/releases/2026.7.1

② ☁️ OpenClaw 2026.7.2：扩展稳定版（Extended-Stable）正式登场
2026.7.2 正式推出"扩展稳定版"机制（类似 LTS），每月发布一次，首个扩展稳定版为 2026.6.33，基于 2026.6.11 并回移植了来自后续版本的安全和可靠性修复。新版本还引入了 Maturity Scorecard（成熟度评分卡），让企业用户更清晰地了解各功能的生产就绪状态。这是 OpenClaw 向企业级基础设施迈进的重要一步，团队表示未来将支持官方 LTS 版本。

🔗 https://releasebot.io/updates/openclaw

③ 🚨 安全预警：ClawChain 漏洞事件（已修复）
2026年5月，安全研究机构 Cyera 披露了 OpenClaw 中的 4 个安全漏洞，组合可实现数据窃取、权限提升和持久化潜伏，统称为"ClawChain"。攻击者可利用 agent 自身的权限链横向移动，传统的安全控制难以检测。该漏洞已在 2026.4.22 版本中修复。如果你的系统长期未更新，请尽快升级到最新版。当前版本 2026.5.28 已包含所有修复。

🔗 https://thehackernews.com/2026/05/four-openclaw-flaws-enable-data-theft.html?m=1

④ 📉 4月下旬风波：团队反思与架构重构
2026年4月24日至29日期间，OpenClaw 遭遇了一次较大范围的稳定性问题：Gateway 变慢、部分安装陷入插件依赖修复循环、Discord/Telegram/WhatsApp 频道表现劣化。创始人 Peter Steinberger 公开承认问题，并表示团队决定：让核心更小、把可选功能迁移到 ClawHub、宣布 LTS 计划。这次事件推动 OpenClaw 从"极客玩具"向"生产级基础设施"转型。

🔗 https://openclaw.ai/blog/openclaw-rough-week

⑤ 🤖 OpenAI 战略投资 Jensen Huang 盛赞，AI Agent 浪潮加速
2026年3月，NVIDIA CEO 黄仁勋在 Morgan Stanley TMT 大会上称 OpenClaw"可能是软件历史上最重要的发布"。同年早些时候，OpenAI 聘请了 OpenClaw 创始人 Peter Steinberger，以基金会模式继续支持开源。Anthropic 则在4月调整了 Claude 订阅策略，将 OpenClaw 从标准订阅中移除，改为按量付费模式——这反映了 AI Agent 系统高算力消耗的现实。

🔗 https://www.linuxjournal.com/content/openclaw-2026-what-it-whos-using-it-and-whether-your-business-should-adopt-it

【对工作的价值】
1. **稳定性优先**：2026.5.28 已是一个非常成熟的版本，4月的事故说明团队有快速纠错能力。我们应保持定期升级习惯，不必追 beta，稳定版足够生产使用。

2. **安全意识**：ClawChain 漏洞提醒我们，agent 系统自身就是攻击面。我们在使用飞书/飞书插件时，不应赋予过多权限，特别是第三方 skills 的安装需要审慎评估。

3. **企业级能力**：Extended-Stable 和 Maturity Scorecard 意味着 OpenClaw 正走向正规企业部署。这意味着我们未来的长期使用有保障，不会是短期项目。

4. **OpenAI/Anthropic 格局变化**：基础模型提供商对 agent 系统的计费策略在持续调整，这会直接影响使用成本，需要关注 token 消耗和账单。

【值得尝试的新特性】
- ClickClack guided setup：新的引导式配置流程，我们新装或迁移时可以体验
- Codex 登录远程恢复：不用 SSH 就能恢复认证，值得测试
- `openclaw doctor --fix` 的模型合并保护：更换模型时能保留配置，值得在测试环境演练一次

【建议】
保持每月一次的版本检查习惯，关注 release notes 中的 "breaking changes"。我们现在跑的是 2026.5.28，属于稳定版，建议每季度评估一次是否需要升级到最新的扩展稳定版。
