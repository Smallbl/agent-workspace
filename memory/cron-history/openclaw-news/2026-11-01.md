### 1. 官方发布 2026.10.9：安全依赖大扫荡 + 更新回滚不再"变砖"

本轮一次性修补了多条高危运行时依赖：fast-uri 4.2.3 现在会拒绝畸形 URI scheme/host，堵住了 MCP schema 校验中的绕过；A2UI 与 Discord 内嵌 SDK 对超大 Zod 集合提前拒绝；IMAP 发件人解析升级到 nodemailer 10.1.4，伪造发件人无法再通过 sender token 校验；Microsoft Teams 换用修补后的 MSAL 7.1.1。同时，失败的 npm 回滚不再把已安装包留在"半残"状态，Git 回滚会保留运维人员的手工修改。**为什么重要**：这是我们这套"主Agent + 子Agent + 飞书 + 定时任务"体系最相关的一版——大量内容来自外部（飞书消息、网页、GitHub），凭据泄露和更新变砖是最大风险点。
原文链接：https://github.com/openclaw/openclaw/releases/tag/v2026.10.9

### 2. gateway-only 稳定通道 2026.9.36（extended-stable，相当于 LTS）

官方在 9 月底版本线上单独发布了长期支持通道：包含关键安全更新、可靠性与性能修复，以及新的模型支持，当前主线最新为 2026.10.9。它把 `tools.fs.workspaceOnly` 正确传递到 Gateway 构建的工具上（委派和媒体工具仍受工作区边界约束），并修复了 Teams 白名单"未解析条目反而放行全员"这类危险默认。**为什么重要**：如果王不希望频繁追 beta，可以走这条 LTS 通道，风险最低；我们当前的 2026.9.5 恰好就是 9 月底的基线，升级路径最短。
原文链接：https://github.com/openclaw/openclaw/releases/tag/v2026.9.36

### 3. 2026.10.6 起强制要求打过安全补丁的 Node 运行时

从 10.6 开始，OpenClaw 要求 Node 24.22.1+（24 系）或 26.12.1+（26 系），以规避 2026 年 10 月 Node.js 安全更新中被攻陷证书签发的 TLS 信任链；Docker 镜像内置 Node 24.22.1，`openclaw update` 在旧 Node 上会拒绝执行并给出恢复指引（而不是把在跑的安装搞坏）。10.10-beta.5 又把这条从"硬性要求"放宽为"安全建议"（`>=24.16.0 <25 || >=26.1.0`），同时修掉了 Node 26 worker 在 stdin 为文件时中止的问题。**为什么重要**：我们的豆浆跑在 Mac mini 上（当前 Node v26.7.0），升级 OpenClaw 前必须先确认 Node 版本满足要求，否则 update 会被拒。
原文链接：
- https://github.com/openclaw/openclaw/releases/tag/v2026.10.6
- https://github.com/openclaw/openclaw/releases/tag/v2026.10.10-beta.5

### 4. Gateway 流式回复卡死修复 + Cron 补跑不再丢（10.10-beta.5）

这是最新 beta 的四大亮点之一：回复里包含类工具调用 XML、看起来像工具调用、或长 HTML 在半个标签处截断时，Gateway 不再卡住不动。同时修复了多行 `/btw`、`/loop`、`/acp` 转向输入被吞、旁白回复在工具发送后消失或重复等一堆"话说不完整"的问题。Cron 方面：存储的 next run 时间过期导致错过的时段不再被丢弃，Gateway 重启后的启动补跑也会被准入。**为什么重要**：这个每日简报任务本身就是 Cron + 流式长回复 + HTML 输出的组合，正好是这次修复的靶心。
原文链接：https://github.com/openclaw/openclaw/releases/tag/v2026.10.10-beta.5

### 5. 2026.10.8：桌面平台服务安装与会话恢复的稳定性飞跃

macOS 上被删掉 plist 的 launchd 注册可以恢复，Linux 在 Ubuntu 默认 umask 下会创建私有状态目录而不是被拒绝安装，macOS 更新器会等在服务的 Gateway 释放数据库后再跑 Doctor。会话侧：被 kill 的运行会释放重启恢复栅栏，被中断或刚被接纳的子会话在 Gateway 重启后能恢复，Control UI 的"忘记发送"重试会真正把回复投出去。**为什么重要**：我们目前靠 `~/.scripts/safe-gateway-restart.sh` 手工规避"重启丢消息"，官方这一版的恢复机制可以让我们逐步放心重启。
原文链接：https://github.com/openclaw/openclaw/releases/tag/v2026.10.8

## 【豆浆学习笔记】

**一、版本现状与建议**
本地 2026.9.5，最新稳定 2026.10.9。跨度约 5 个小版本，积压的安全修复相当可观（尤其 10.9 的凭据与依赖修补），不建议长期拖下去。但升级前有两个前置检查必须做：① 确认 Node 版本——本机 v26.7.0 落在 `>=26.1.0` 区间内，满足 beta 的宽松要求，但若走 10.6+ 稳定线则需要 26.12.1+；② 按 AGENTS.md 的规范，改配置/升级前先备份、走 `safe-gateway-restart.sh` 而不是裸 `openclaw gateway restart`。建议下一步先做一次配置与 memory 目录的备份，再评估升级。

**二、可以直接落到我们工作流上的点**
1. **`tools.fs.workspaceOnly` 现在真正生效到 Gateway 构建的工具**——这条对"主Agent 绝不自己写代码"的铁律是加固而不是替代：即使子Agent 通过 Gateway 委派，文件改动仍需审批，媒体工具也出不了工作区。建议王批准我把这项写进 OpenClaw 配置，形成第二道技术防线。
2. **Cron 补跑与时段不丢**——我们的日报、简报类任务全部依赖 Cron。现在错过时段会被丢弃、重启后的补跑被拒，这两个修复直接提升简报的送达率；升级后可以适度降低"必须准点跑"的焦虑。
3. **Gateway 流式回复卡死修复**——这个每日简报要输出长中文 + HTML/表格 + 工具调用痕迹，属于典型高危形态。这次修复值得单独感谢一下作者。
4. **Gateway 重启恢复栅栏与子会话恢复**——以后配置变更可以更放心地重启，减少"改完配置丢消息"的焦虑，也减少用 `safe-gateway-restart.sh` 的等待成本。
5. **`openclaw update` 拒绝在旧 Node 上执行并给恢复指引**——以后升级失败不再是玄学，可以直接照着指引走。

**三、值得尝试的新特性**
- **2026.10.8 的"首次 OpenAI 配置不再把模型选择器锁死成单个模型"**——如果我们后续要接入 OpenAI 官方账号，这条直接降低了配置成本。
- **扩展稳定通道（LTS）**——考虑到我们的使用偏"稳定压倒一切"，可以研究是否有 LTS 通道的固定安装方式，把 beta 隔离在外。
- **10.10-beta.5 的安全边界加固**（exec 白名单模式下 `test -v` 需要审批、通用 node invoke 拒绝浏览器代理命令、沙箱子进程不能解析到 CLI 后端模型、审计符号链接工作区技能根）——这几条读起来像是专门针对真实攻击面写的，值得重点关注后续是否还有类似的边界修复。

**四、本次任务的局限（如实记录）**
- Tavily 搜索接口返回 432 错误："This request exceeds your plan's set usage limit"，即 **Tavily 套餐额度已用尽**，`tavily_search` / `tavily_extract` / `web_search` 三者均不可用。本期资讯改为直接走 GitHub Releases API 抓取官方 changelog，因此内容权威但**未能覆盖社区博客、第三方评测等外围动态**。
- 建议：要么升级 Tavily 套餐，要么在网关配置里为搜索工具配置一个备用 provider（例如 Brave / Perplexity），以免后续日报质量受单一额度限制。

**五、一句话结论**
这一轮 OpenClaw 的主线非常清晰：**安全边界收紧 + 更新/重启不再丢状态 + 流式与定时任务的可靠性修复**。对我们这种"一个主Agent + 飞书 + 多个定时任务 + 长期记忆"的用法，后两类修复的价值最直接，建议尽快升级到 2026.10.9 稳定版，并在升级前完成 Node 版本确认与配置备份。
