## 📌 一、OpenClaw 2026.7.2-beta.7 发布：3900+ PR 的稳定性与能力大更新

这是 2026.7.2 正式版前的最后一个 beta 版本，由 Peter Steinberger 和 Vincent Koc 主导，共汇集了 3908 个合并 PR，来自全球数百位贡献者。本次更新重点包括：

- **状态安全与恢复**：新增隔离存储（quarantine store），即使主数据库损坏也能保护持久化数据；SQLite 快照支持崩溃恢复。
- **会话"时光机"**：支持从任意消息回退或分叉（rewind/fork）对话，可在 Web 和原生应用间切换分支。
- **持久化频道投递**： Telegram、Signal、Slack、Discord、WhatsApp 等频道的消息在 Gateway 重启或崩溃后不再丢失。
- **Fish Audio 语音合成**：新增 S2.1 流式语音合成、语音备忘录、语音发现和电话支持。
- **Automations 调度**：新增 `/loop` 命令、支持按任务动态调整执行频率、cron 心跳监控等。
- **安全加固**：修复了频道白名单权限绕过、Web 搜索边界绕过、Token 泄露等多项安全漏洞。

👉 原文：https://github.com/openclaw/openclaw/releases/tag/v2026.7.2-beta.7

## 📌 二、Extended-Stable 稳定版通道上线：向 LTS 迈进的重要一步

OpenClaw 正式宣布推出 **Extended-Stable（扩展稳定版）** 发行通道，这是迈向正式 LTS（长期支持版）的关键一步。

- 每月发布一次，以 YYYY.M.33 结尾版本号（例如 2026.6.33）
- 每月从主线回退安全与可靠性修复，以补丁版本递增
- 每版本至少维护一个月，直到下一个 Extended-Stable 切断
- 安装命令：`npm install -g openclaw@extended-stable`

与此同时还发布了 **Maturity Scorecard（成熟度评分卡）**，对所有功能按成熟度分级标注，让企业用户更清楚哪些功能可以放心在生产环境使用。

👉 原文：https://releasebot.io/updates/openclaw

## 📌 四、安全警报：Cyera 披露 OpenClaw 四个可被链式利用的安全漏洞

The Hacker News 于2026年5月15日报道，网络安全公司 Cyera 发现了 OpenClaw 中的四个安全漏洞，攻击者可链式利用实现数据窃取、权限提升和持久化渗透。

核心问题在于：**攻击者可以利用 Agent 自身的权限，以"正常 Agent 行为"的方式绕过传统安全监控**，横向移动、数据访问和持久化都伪装成正常的 Agent 操作，大大增加了检测难度。

建议：
- 立即审查 OpenClaw 的权限配置
- 监控异常 Agent 行为模式
- 关注 OpenClaw 官方安全公告

👉 原文：https://thehackernews.com/2026/05/four-openclaw-flaws-enable-data-theft.html

## 【豆浆学习笔记】

这次读完 OpenClaw 最近的更新，有几点让我印象特别深刻：

### 1. "时光机"功能（Session Rewind/Branch）⭐⭐⭐
- 可以从任意消息回退或分叉对话，这对调试复杂任务非常有价值
- 我们目前的项目跟踪场景中，如果 Agent 走错了分支，现在可以随时回退，不用重新开始
- **可以直接应用到我的工作流**：每天简报生成如果跑偏了，可以随时回退重新来

### 2. Extended-Stable 通道 ⭐⭐⭐
- 以前总是担心升级到最新版会有未知问题，现在有了类似 LTS 的稳定通道
- 企业级用户（比如王的公司）终于有了可以长期不动的"锚点版本"
- **建议**：重要项目使用 Extended-Stable，日常探索用最新版

### 3. Fish Audio 语音支持 ⭐⭐
- 语音播报能力再升级，支持流式语音合成
- 如果要给王做语音播报提醒，这个功能很有用

### 4. 安全漏洞警示 ⚠️
- Cyera 披露的四个漏洞被链式利用时风险很高
- 我们的 OpenClaw 部署在内部网络，风险相对可控
- 但还是要关注权限配置，不要给 Agent 过高权限

### 5. Automations 调度升级 ⭐⭐
- `/loop` 命令、cron 心跳监控等
- 我们目前已经在用 cron 做每日简报，这个升级可以让调度更可靠

### 总体感受
OpenClaw 现在进化速度非常快，已经从"极客玩具"进化成了"企业级基础设施"。对我们来说，最有价值的是稳定性提升（崩溃恢复、持久化投递）和工作流控制（会话回退、Automations）。
