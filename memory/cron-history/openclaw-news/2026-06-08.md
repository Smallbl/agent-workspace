##📦 头条：Skill Workshop 正式上线（2026.6.3）

OpenClaw 上线了全新的 Skill Workshop 功能，可以将 Agent 工作流转化为可复用的 Skill（技能），在正式应用前支持审查和修改。这改变了技能的创建方式——不再是直接改动生产环境，而是先review再部署。

👉 对我们：可以用它把日常任务封装成标准化技能，团队共享更安全。飞书通知、任务派发、日报生成这些重复工作都可以做成可复用 Skill。

🔗 https://openclaw.ai

## 🔐 NVIDIA 合作：ClawHub 技能安全升级（2026.6.1）

OpenClaw 与 NVIDIA 合作推进 Skill 安全建设：每个 ClawHub 上的 Skill 现在都附带 Skill Card（说明来源和用途），并通过 SkillSpector 扫描隐藏指令和 Agent 风险。同时，OpenClaw 在 Hugging Face 上公开了涵盖 67,453 个公开技能版本的安全扫描数据集。

👉 对我们：Skill 来源更透明，引入第三方 Skill 时更有安全保障，放心使用社区生态。

🔗 https://openclaw.ai

## 🛡️ 企业级执行防护 Auto Mode（2026.5.31）

新版本引入 Exec Auto Mode：先运行安全策略，低风险操作自动放行，高风险操作人工审核，始终保持人类在环。这让自动化执行既高效又安全，适合在正式工作流中大胆使用。

👉 对我们：可以把定时任务、Cron 自动化跑得更放心，不必担心危险命令误执行。

🔗 https://openclaw.ai

## 📝 【豆浆学习笔记】

### 对我和团队的直接价值

1. **Skill Workshop 是重点关注方向**
   我们目前的"任务派发"模式其实可以进一步封装成团队 Skill——把派发格式、验证标准都做成模板，一次构建、重复使用，减少每次重新描述的成本。值得探索。

2. **Auto Mode 让 Cron 任务更安全**
   以前跑自动化命令总有点担心，有了策略先行的 Auto Mode，可以把更多日常巡检、报表生成任务自动化，而不必守在机器旁边。

3. **Agent 恢复能力提升对长时间任务有意义**
   我们有些跨日任务（日报生成、项目进度汇总），中断恢复变好意味着这类任务可以更放心地交给 Agent 完成。

4. **NVIDIA 安全合作信号积极**
   Skill 生态有了安全背书，未来引入社区 Skill 会更放心。这也意味着 ClawHub 生态会越来越重要，提前熟悉很有价值。

### 可以尝试的新特性

- 把飞书消息同步、项目进度查询封装为可复用 Skill
- 开启 Exec Auto Mode，配置低危命令白名单
- 尝试用 Skill Workshop 把"每日简报生成"做成自动化 Skill

### 长期观察点

- OpenClaw 已移交 OpenClaw Foundation，项目持续性有保障
- 2026年被社区认为是"通用AI Agent元年"，OpenClaw 正在成为标准基础设施
- 随着 NVIDIA、OpenAI 的介入，企业级安全/治理功能会越来越完善
