1️⃣ OpenClaw 2026.9.7 发布：性能大幅提升
━━━━━━━━━━━━━━━━━━━━
OpenClaw 于 9 月底发布了 2026.9.7 版本，包含 2818 个 PR、518 次直接提交和 344 位贡献者。新版本在负载下响应更快、长对话更流畅，升级时备份和回滚保护更强，并修复了从 2026.9.5 升级时的问题。新增 OpenAI Agents API 和"使用 ChatGPT 登录"（Beta）支持，同时改进了 Mac、iPhone 和 iPad 上的聊天体验，以及重启后继续工作的能力。
👉 https://docs.openclaw.ai/releases/2026.9.7

━━━━━━━━━━━━━━━━━━━━
2️⃣ OpenClaw 基金会在六月正式成立
━━━━━━━━━━━━━━━━━━━━
OpenClaw 项目在 2026 年 6 月正式转型为非营利组织，成立了 OpenClaw Foundation，拥有全职团队和世界级合作伙伴，致力于"让每个人都能使用个人 AI"。创始人 Peter Steinberger 今年 2 月宣布加入 OpenAI 后，项目改由非营利基金会接管，OpenAI 承诺继续以 MIT 许可证赞助该项目保持开源。项目于 2025 年 11 月以 Clawdbot 起步，2026 年 1 月两度更名，3 月初 GitHub 星标已突破 25 万。
👉 https://openclaw.ai/blog

━━━━━━━━━━━━━━━━━━━━
3️⃣ OpenClaw 2.0 意外发布：简化安装+浏览器体验
━━━━━━━━━━━━━━━━━━━━
8 月 30 日官方博客详细讲述了 OpenClaw 2.0 的诞生过程——原本只是追求更简单的安装流程和一流的浏览器体验，最终演变成了一次重大版本迭代。这次更新让新用户入门门槛更低，同时也让浏览器端的体验更加完善。
👉 https://openclaw.ai/blog（文章：OpenClaw 2.0, Accidentally）

━━━━━━━━━━━━━━━━━━━━
4️⃣ 扩展稳定版发布通道上线 + 长期支持路线图明晰
━━━━━━━━━━━━━━━━━━━━
OpenClaw 推出了"扩展稳定版"（extended-stable）作为 LTS 的等价物，并配套发布了公开的成熟度评分卡（maturity scorecard），方便对稳定性有高要求的团队选择适合生产环境的版本。例如 2026.8.33 就是最新的扩展稳定版，包含关键安全更新、可靠性修复和性能优化，并新增 Meta Muse Spark 1.3、Anthropic Fable 5.1、OpenAI GPT-6 Astra 及 GPT Image 2.5 等模型支持。
👉 https://releasebot.io/updates/openclaw

━━━━━━━━━━━━━━━━━━━━
5️⃣ NVIDIA 合作 + ClawHub 安全强化：技能卡片和扫描
━━━━━━━━━━━━━━━━━━━━
OpenClaw 与 NVIDIA 合作强化技能安全，现在每个 ClawHub 技能都附带"技能卡片"（Skill Card）说明其功能和来源，并通过 SkillSpector 扫描隐藏指令和代理风险。同时新增了企业级 exec 审批的"自动模式"——可选择开启"政策先行、低风险误报人工复核"的安全机制，让自动化和人工监督达到更好的平衡。
👉 https://openclaw.ai/blog（安全相关文章）

🎯 对我们工作的价值：
- 扩展稳定版（extended-stable）对我们这种生产环境很重要——以后选版本有据可依，不必追最新版，可以等稳定版发布再升级
- OpenAI Agents API 支持可能对我们后续定制工作流有帮助
- 安全加固（环境变量隔离、节点通信信任模型）是实打实的提升，我们跑在服务器上的场景尤其需要关注

🚀 可以尝试的新特性：
- 重启后继续工作的能力——很适合我们这种多任务切换的场景，值得测试
- Sign in with ChatGPT（Beta）——如果团队使用 ChatGPT 账号，统一认证会更方便
- Skill Workshop 功能——可以将我们重复的工作流程固化下来，创建自己的技能库

⚠️ 注意事项：
- 4 月底有过一次比较严重的故障（2026.4.24/4.29），导致部分实例变慢、Discord/Telegram 频道异常，团队升级大版本时还是要留意发布说明
- 4 月那波安全更新覆盖了权限隔离、工作区完整性、网络防御，建议确认当前版本已包含这些修复
