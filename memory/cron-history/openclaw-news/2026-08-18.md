# OpenClaw 日报 | 2026-08-18

🔧 本地版本：OpenClaw 2026.5.28 (e932160)

## 资讯列表

### 1. OpenClaw 2026.7.1 正式版发布：Control UI 全面改版 + 移动端重大更新

这是7月中旬的大版本更新，带来 Control UI（控制界面）全面重新设计，包括会话管理、工作区、用法统计等核心模块重构。iOS 和 Android 也获得重大更新，支持滚动位置记忆、Voice 功能优化等。Telegram、Slack、Discord 等渠道也同步收到大量改进。

🔗 https://docs.openclaw.ai/releases/2026.7.1

---

### 2. OpenClaw 2026.8.1-beta.2 预览版发布（8月15日）

最新预发布版本，包含 Control UI 更新恢复机制改进——当 Gateway 重启后，"发现新版本"按钮现在能正确等待并自动重载，不再出现手动刷新的困扰。同时修复了 npm 包大小（减少约 3.18 MB），以及 macOS/Windows/Linux 的多项稳定性修复。

🔗 https://github.com/openclaw/openclaw/releases

---

### 3. 扩展稳定版（Extended-Stable）频道正式推出

OpenClaw 宣布推出 LTS（长期支持）版本的扩展稳定版频道，目前对应 2026.6.34。该版本专注于安全加固和可靠性修复，适合需要稳定运行不追新的企业用户。通过 `openclaw update --channel extended-stable` 可切换。

🔗 https://github.com/openclaw/openclaw/releases

---

### 4. OpenClaw 2026.7.2-beta.7 更新：Cron 定时任务可靠性大幅提升

7月底/8月初的 beta 版本重点改善了 Cron 定时任务的可靠性，包括：一次性任务和启动任务恢复、脚本状态持久化、任务 ID 精确查找等。同时新增了"工作树管理"（按数量和总大小配置清理限制）、Codex 用量显示、Discord 语音频道参与者变化通知等实用功能。

🔗 https://github.com/openclaw/openclaw/releases

---

### 5. 安全公告：2026年多起 CVE 漏洞已修复

OpenClaw 此前经历过"艰难的一周"（4月底版本问题导致服务不稳定），团队已进行全面修复。同时 2026 年披露的多项 CVE 漏洞（包括 CVE-2026-44115 凭证泄露、CVE-2026-44118 权限提升等）已在后续版本中修复。建议尽快升级到 2026.6.34 或更新版本。

🔗 https://openclaw.ai/blog/openclaw-rough-week
