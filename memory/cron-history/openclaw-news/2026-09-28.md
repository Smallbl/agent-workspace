# 【OpenClaw日报】📅2026-09-28

🚀 OpenClaw 近期最新动态简报
当前版本：2026.9.5 | 发布日期：2026年9月28日

## 资讯一：OpenClaw 2.0（v2026.8.1）正式发布——史上最大更新

**这是什么：** 2026年8月发布的里程碑版本，被官方称为"OpenClaw 2.0"。覆盖安装、消息传递、记忆管理、技能系统、模型支持、自动化、前端界面、插件体系、安全性等几乎所有层面。

**为什么重要：** 全新 Web UI（Control UI）将对话置于核心位置；Sessions 和 transcripts 迁移至 SQLite 提升数据可靠性；内存管理新增"记忆梦境"（Memory Dreaming）实验特性；技能创建/验证/安装流程全面重构。

原文链接：https://docs.openclaw.ai/releases/2026.8.1

---

## 资讯二：内置视频&音乐生成功能上线（v2026.4.5+）

**这是什么：** 2026年4月的重磅更新，视频生成和音乐生成能力直接内置到核心工具链。同时新增实验性"长期记忆"（Memory Dreaming）、12种新 UI 语言、ClawHub 与技能面板深度集成。

**为什么重要：** 极大扩展了作为个人 AI 助手的能力边界，创意工作者和内容团队可直接在对话中生成多媒体内容。Memory Dreaming 意味着 Agent 开始具备跨对话的上下文记忆能力。

原文链接：https://www.youtube.com/watch?v=WMd7OjE-90A

## 资讯三：2026.4.24～4.29 质量事故与后续改进

**发生了什么：** 4月24日至29日连续发布多个问题版本，导致网关变慢、插件依赖修复循环、渠道行为异常、用户被迫降级。

**官方回应：** 5月5日公开发文致歉，宣布核心重构方向——核心做小、可选功能移至 ClawHub、单独发布 LTS。目标是"更小、更安全，同时保持无聊般的可靠性"。

**为什么重要：** 推动 OpenClaw 从"功能丰富的个人项目"向"可靠的基础设施级产品"转型，对企业用户是重要质量信号。

原文链接：https://openclaw.ai/blog/openclaw-rough-week

## 资讯四：2026.9.x 系列更新——安全与稳定性持续打磨

**这是什么：** 9月份修复：macOS 应用重建（修复启动崩溃）、Code Mode 验证漏洞、侧边栏对话阻塞输入问题、数据库恢复时响应性优化、并发调度器改进。

**为什么重要：** 体现4月事故后对稳定性和安全性的重视。并发请求优先级优化对运行自动化任务（定时简报、数据拉取、后台检查）的用户尤为实用。

原文链接：https://releasebot.io/updates/openclaw

## 资讯五：Anthropic 调整策略对 OpenClaw 的影响

**背景：** 2026年4月，Anthropic 将 OpenClaw 从标准 Claude 订阅中移除，改为按量付费模式，理由是 Agent 类系统产生异常高的计算需求。

**影响：** 部分用户成本上升或需要重新配置，但也推动了社区探索更多元模型提供商（Cohere、Fireworks AI、StepFun 等）。

原文链接：https://www.linuxjournal.com/content/openclaw-2026-what-it-whos-using-it-and-whether-your-business-should-adopt-it

## 【豆浆学习笔记】

**这些更新对我和我的团队有什么价值？**

1. **OpenClaw 2.0 的记忆和技能系统**：跨会话上下文记忆能力可以让我们在跟踪多个项目进度时建立更持久的上下文——Agent 能记住之前的决策历史，而不只是单次对话。

2. **内置视频&音乐生成**：考虑到我们涉及大量招标文件、宣传材料的场景，自动化生成多媒体内容可能有用武之地，值得在非关键场景下测试。

3. **安全与稳定性改进**：4月事故提醒——重要业务不应依赖"最新版本"，应关注 LTS 发布计划。生产环境升级前应关注 release notes。

4. **并发调度优化**：我们已有多个定时任务在跑（日报、提醒等），9月份的调度器改进应该能让这些任务运行得更顺畅。

**值得尝试的新特性：**
- 在测试环境中体验"Memory Dreaming"，看跨会话上下文复用是否真的有效
- 尝试用内置视频/音乐生成来做招标材料的快速预览

**下一步建议：**
- 关注官方 LTS 公告，选择一个稳定的长期支持版本作为生产基准
- 整理一份我们当前工作流的"OpenClaw 能力对照表"，找出自动化盲区
