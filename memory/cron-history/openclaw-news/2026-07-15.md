# OpenClaw 日报 | 2026-07-15

🔹 OpenClaw 正式成立非营利基金会，进入机构化时代
六个月内从一个周末项目发展成 501(c)(3) 非营利组织，拥有全职工程团队、38.2 万 GitHub Stars 和每周 450 万次安装。OpenClaw 基金会的成立标志着项目从个人主导转向社区治理，对长期用户而言意味着更稳定的支持和更透明的决策流程。
📎 https://www.bighatgroup.com/blog/openclaw-weekly-2026-07-13

🔹 v2026.7.1 发布：Control UI 全面改版 + 官方 App 大更新
7月13日发布的 v2026.7.1 是今年以来最重要的版本之一。主要更新包括：Control UI（聊天、会话、工作区、使用统计）全面重新设计；iOS/Android/macOS 官方 App 重大更新；新增 GPT-5.6、Tencent Hy3、Meta Muse Spark 1.1 等模型支持；Telegram/Slack/Discord/Apple Messages 全面加强；修复了 Gateway 崩溃循环问题、远程浏览器控制、工作区终端等多项可靠性问题。
📎 https://docs.openclaw.ai/releases/2026.7.1

🔹 MCP 2026-07-28 无状态规范发布倒计时（15天后）
MCP（Model Context Protocol）即将迎来自发布以来最大修订：彻底移除协议级会话，`initialize`/`initialized` 握手取消，`Mcp-Session-Id` 请求头取消，粘性路由不再需要。这意味着任何服务器实例都可以处理任何请求，实现简单的轮询负载均衡。对使用 MCP 插件的团队有重大影响。
📎 https://www.bighatgroup.com/blog/openclaw-weekly-2026-07-13

🔹 OpenClaw 创始人：2026年将是通用 AI Agent 之年
创始人 Peter Steinberger 在东京接受采访时表示，AI 尚不是普通人的必备个人助手，但"今年你会看到更多这样的应用，因为今年是 Agent 元年"。他还提到仍有很多工作要做来让 AI 变得更好，但需求正在加速增长。
📎 https://techxplore.com/news/2026-03-openclaw-creator-year-general-ai.html

🔹 GitHub Copilot 9月1日大幅削减 AI 额度
GitHub Copilot 的 AI Credit 计费模式将于9月1日重大调整：Business 版从每用户每月 3000 Credits 削减至 1900（减少37%），Enterprise 版从 7000 削减至 3900（减少44%）。基础价格不变，但计量空间大幅缩水。建议团队现在就开始监控消耗并准备预算调整。
📎 https://www.bighatgroup.com/blog/openclaw-weekly-2026-07-13
