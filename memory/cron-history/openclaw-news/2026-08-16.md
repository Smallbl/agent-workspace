## 5条最新资讯

### ① 🔐 OpenClaw 紧急修复4个高危漏洞（CVE-2026-44112/44113/44115/44118）

2026年5月，网络安全公司 Cyera 披露了 OpenClaw 中的4个安全漏洞，统称为"Claw Chain"漏洞链，可被利用实现数据窃取、权限提升和持久化控制。其中最严重的 CVE-2026-44112 CVSS评分高达9.6分，涉及 OpenShell 沙箱的 TOCTOU（检查时间-使用时间）竞态条件漏洞。

官方已在后续版本中修复：MCP 环回运行时现分别颁发 owner/non-owner 令牌，不再信任可伪造的 senderIsOwner 头；沙箱路径遍历和 heredoc 命令注入漏洞均已封堵。

> 如果你运行 OpenClaw 处理过不受信任的内容，务必确认已升级至最新版本。

🔗 https://thehackernews.com/2026/05/four-openclaw-flaws-enable-data-theft.html

## 🧠 豆浆学习笔记

### 这些更新对我和团队有什么价值？

**1. 安全漏洞修复是最高优先级**
我们正在用 OpenClaw 处理飞书消息、项目文件、招标数据等敏感信息。Claw Chain 漏洞虽然需要攻击者先建立立足点，但一旦被利用后果严重。建议：
→ 检查当前版本是否已包含 CVE 修复（2026.5.28 之前的版本可能未完全修复）
→ 关注 npm 最新稳定版 2026.7.1-2 的升级计划

**2. Session 分支功能值得期待**
「Session 回溯与分支」对复杂项目跟踪很有用——我们可以回退到某个历史状态尝试不同路径，而不影响主线。这对多项目并行跟进的场景特别有价值。留意正式版发布。

**3. Android Talk Mode 语音中继**
目前豆浆运行在 Mac mini 上，但如果王外出需要用手机语音控制，Android 端的实时语音中继功能值得关注。这是未来移动端入口的一个方向。

**4. Extended-Stable 发布节奏意味着更可靠的升级路径**
企业级稳定性保证 + 明确的长支持周期，意味着我们可以减少对「升级导致故障」的顾虑，长期部署更有信心。

**5. 治理结构改善了项目可持续性**
Peter 加入 OpenAI + 基金会托管，说明 OpenClaw 不会很快消失。对于我们在生产环境中重度依赖它是好消息。

### 下一步行动建议
- ⬜ 评估 2026.7.1-2 稳定版升级计划（先在非生产环境测试）
- ⬜ 确认所有敏感操作的沙箱边界是否完整
- ⬜ 持续关注 2026.8.1 正式版发布动态
