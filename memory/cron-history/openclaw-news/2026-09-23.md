# OpenClaw 日报 | 2026-09-23

## 1. OpenClaw 2.0 正式发布：凭证安全防护成为核心亮点

OpenClaw 2.0 于2026年9月1日发布，这是一个标志性的重要版本。该版本在七周内合并了16,000个PR，展示了更高的稳定性。

最值得关注的是凭证安全防护的重大升级：
- 新增"密钥保险库"（Secret Vault）功能，允许用户将敏感凭证存储在加密保护区域
- 支持团队级别的凭证管理，方便多人协作时安全共享
- 引入"出口代理"（Egress Proxy），可限制受保护凭证只能发送到用户明确批准的目标主机
- 即使不小心把密码粘贴到AI聊天窗口也能得到保护

**适用场景：** 对于在多系统、多供应商环境中工作的团队（如招投标项目涉及多个供应商系统），这个版本大幅提升了安全性。

🔗 https://openclaws.io/blog/openclaw-2-0-release

## 2. OpenClaw 9.x 密集发布：11天发布5个版本，可靠性大幅提升

2026年9月2日至12日，OpenClaw团队在11天内连续发布了8.2到9.4共5个版本。主要改进包括：
- **GPT-6 Astra 和 Meta Muse Spark 1.3 模型支持**
- **更智能的更新机制**：更新程序会"预演"在真正执行前验证路径
- **背景会话（Background Sessions）**：支持将任务放到后台运行
- **更可靠的消息投递**：修复了消息发送失败、回复丢失的问题

🔗 https://docs.openclaw.ai/releases
