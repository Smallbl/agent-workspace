**1. 2026.10.7 稳定版发布：会话恢复与更新稳定性大幅加固**

10 月 24 日发布的 2026.10.7 是一次以可靠性为主的补丁版本（61 个 PR、54 位贡献者）。核心是修复会话中断后无法恢复、回复丢失、上下文被截断等问题：被中断的对话现在保留恢复溯源信息和未完成的工具结果；插件重载后排队中的回复能用当前 provider 继续投递；供应商压缩长对话后 Agent 也能继续工作而不再报"工具被截断"的假警告。

为什么重要：我们每天靠定时任务+飞书推送干活，任何"回复丢失"或"会话卡死"都是实打实的业务事故。macOS 端还修复了本地慢模型下 Talk 语音只播半句的问题。

原文链接：https://docs.openclaw.ai/releases/2026.10.7

**2. ⚠️ 2026.10.6 起强制要求打过安全补丁的 Node 运行时**

2026.10.6 及之后的版本要求 Node 24.22.1+ 或 26.12.1+，原因是 2026 年 10 月 Node.js 安全更新涉及的受损证书签发的 TLS 链。OpenClaw 的做法是：Docker 镜像内置 Node 24.22.1，安装器自动选补丁运行时；如果 Node 版本太旧，`openclaw update` 会**拒绝升级并给出恢复指引**，而不是把当前能跑的实例搞坏。

为什么重要：这直接影响我们能不能升级（见下方学习笔记）。

原文链接：https://github.com/openclaw/openclaw/releases

**3. Skill Workshop 2.0：技能版本对比、Undo 撤回与后台学习开关**

2026.10.5（2250 个 PR、637 位贡献者）重做了 Skill Workshop：现在可以查看技能变更历史、保存多个版本、版本间对比、一键 Undo 回到旧版本，也能归档/恢复技能。技能库最多保留 10 个已保存版本，新会话自动生效。重要提醒：后台学习会把对话和工具内容发给你配置的模型供应商，可能产生额外费用，可以关成 Off（改用 `/learn` 手动触发）。同一版还接入了 Gemini 4 Argon（Google/Vertex）和 Gemini 3.8 Flash。

为什么重要：我们的 AGENTS.md 铁律、技能沉淀流程正好可以用这套版本管理来做可回滚的流程演进。

原文链接：https://docs.openclaw.ai/releases/2026.10.5

**4. 渠道投递正确性修复：飞书/WhatsApp/Telegram/Slack/Discord 全线加固**

2026.10.6 的渠道修复覆盖了 WhatsApp 重试与贴纸、Telegram 相册与双栈回复、Slack 中继恢复、Discord 语音通话回复——不再丢消息或重复发消息。2026.10.5 还修复了"在 CLI 对话中真正新增了可用工具时，下一轮才启动新原生会话"的问题，以及 MCP 服务器在 Gateway 下的持续可用性。

## 【豆浆学习笔记】

**版本现状与一个必须注意的坑：**
我们跑的是 2026.9.5，官方最新是 2026.10.7。但当前 Node 是 **v26.7.0**，而 2026.10.6+ 要求 **26.12.1+**（或 24.22.1+）。也就是说直接 `openclaw update` 会被**拒绝**并提示 Node 版本不够——这正好符合我们 AGENTS.md 里"改配置/升级前先备份、先确认依赖"的红线。

**建议的升级路径（不急，但要排期）：**
1. 先升级 Node 到 26.12.1+（或换 24.22.1+），`node --version` 确认；
2. 备份：`~/.openclaw/` 目录 + workspace 的 memory/ 配置；
3. `openclaw update` → `openclaw doctor --fix` → 用 `bash ~/.scripts/safe-gateway-restart.sh` 重启（不要直接 `openclaw gateway restart`，会丢消息）；
4. 验证：`openclaw status --all`、飞书收发、cron 定时任务是否还在。

**可以直接用到我们工作流里的新特性：**
- **Skill Workshop 2.0 的版本对比 + Undo** → 我们 AGENTS.md 铁律强调"铁律更新/工作流调整"，以后用 Workshop 改技能时能留可回滚版本，不再怕改坏。
- **后台学习开关** → 可以关掉自动学习，避免我们的对话内容被自动送到模型供应商产生额外费用，只用 `/learn` 手动触发。这个对"私有招投标项目资料"场景值得认真评估。
- **`openclaw update status --json`** → 可作为日常巡检项，纳入 heartbeat 检查，落后太多时提醒升级。
- **2026.9.6 Mac 崩溃版要避开**（若我们有人手动装过 9.6，需提醒直接升到 10.x）。
- **10.2 修复了 macOS < 13.3 上 Intel/Rosetta 段错误** → 王的 Mac mini 是 arm64，暂时无影响，但团队内若有 Intel Mac 需注意。

**给王的一句话建议：** 这次升级的收益主要是"不丢消息 + 不丢会话"，对我们这种定时跑批 + 飞书推送的场景价值很高；但 Node 前置条件必须先满足，建议走"升 Node → 备份 → 更新 → doctor → 安全重启"这套稳妥流程，我可以配合在低峰时段执行。
