=== 五、安全事件本机实证（不照抄版本号推断）===
本机 Node v26.7.0 的 tls.rootCertificates 实测（X509Certificate 解析后匹配）：
- 精确匹配 CN=emSign ECC Root CA - G3：**1 张**
- eSign/eMudhra 家族（emSign Root CA - G1、emSign ECC Root CA - G3、emSign Root CA - C1、emSign ECC Root CA - C3）：**共 4 张**
- 另有 2 张 SecureSign Root CA14/15（Cybertrust Japan）系大小写不敏感正则 "eSign" 子串误命中，**不计入** eSign 家族
- Comodo AAA：0 张
结论：**本机 Node 的内置根证书库仍含受影响的 emSign ECC Root CA - G3**（精确 1 张）。本机 Node 26.7.0 低于官方修复版本（22.23.4 / 24.22.1 / 26.12.1）中对应主线的 26.12.1 → 本机 Node 仍信任受影响链。
缓解：OpenClaw 自身的 secret egress proxy 自 2026.11.1 起拒绝该链（见上引原文），升级到 2026.11.3 即覆盖该层；**独立信任库的客户端需自行单独更新**（changelog 原文明确要求 "update clients with independent trust stores separately"）。
