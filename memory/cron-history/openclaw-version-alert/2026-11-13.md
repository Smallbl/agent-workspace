———— 评估（结论基于上述实测正文）————

是否有重大变化:
- 2026.11.3 **明确为安全发布（Security release）**。原文（main/CHANGELOG/2026.11.3.md）：
  「**Security release:** This release fixes certificate verification for worker transfers with blank fingerprints, keeps required-sandbox image previews within allowed folders and reduces credential exposure. Update OpenClaw to receive these fixes.」
  即：修复 worker 传输在指纹为空时的证书校验缺陷、限制沙箱图片预览越界、降低凭据暴露面。
- 无 breaking change：11.3 全文（main/CHANGELOG 与 tag 正文）检索 `breaking` / `Breaking` 命中 0。
- 与本机相关：本机主模型 MiniMax-M2.7 → 11.3 正文 `MiniMax` 命中 0（无相关修复或回归）；飞书为主通道 → `Feishu` 命中 0（无回归条目）。
- macOS LaunchAgent 相关（引用 changelog 原文，非编号推断）：main/CHANGELOG/2026.11.3.md 原文一行：
  「- Fixes a managed macOS Gateway restarting during update maintenance when its LaunchAgent background service remains loaded. Stopping the service no longer by itself causes SQLite migration to reject the captured database as changed. [#187104](https://github.com/openclaw/openclaw/pull/187104). Thanks to [@RomneyDa]…」
  关键词检索结果：`launchd` 0、`kickstart` 0、`LaunchAgent` 1（命中行含描述文字，满足 R11 三条判据）。除此之外，本告警不引用任何「macOS launchd 可能不自动拉起」类传闻（未在权威源检索到对应条目，属社区传闻，未证实）。

安全（eMudhra / 证书信任，本机实证）:
- 本机 Node v26.7.0 的 `tls.rootCertificates`（用 X509Certificate 解析 PEM 后匹配）实测：eSign/eMudhra 家族共 4 张（emSign Root CA - G1、emSign ECC Root CA - G3、emSign Root CA - C1、emSign ECC Root CA - C3），其中**精确 CN 命中 `emSign ECC Root CA - G3` 的为 1 张**。
- 本机 Node 26.7.0 **低于**官方修复版本（22.23.4 / 24.22.1 / 26.12.1）中的 26.12.1 → 本机仍信任受影响根链。
- 官方安装文档同时写明（https://docs.openclaw.ai/install/updating 原文）：「Node 24.16.0+ on the 24.x line, or Node 26.1.0+. Node 24.22.1+/26.12.1+ is strongly recommended for security; older compatible releases warn without blocking the update.」→ 即 26.12.1+ 是**安全地板（强烈建议）**，不是安装准入门槛；两者不互斥。

———— 升级前置（`openclaw doctor` 实测，观测时刻 2026-11-13 09:05 CST）————
1. Session SQLite 未迁移：doctor 报「Legacy entries: 1377; SQLite entries: 1372」「Found 1354 session SQLite issue(s)」→ **必须先停 Gateway**，再执行
   `openclaw doctor --session-sqlite recover --session-sqlite-all-agents`（或 `openclaw doctor --fix`），不能带着未迁移会话直接升级。
   （注：该数字会随迁移推进漂移，此处为 09:05 观测值。）
2. 无 command owner：doctor 报「No command owner is configured」→ `commands.ownerAllowFrom` 未设置，`/update`、重启 Gateway、改配置无授权主体。需先配置 owner。
3. 孤儿 agent 目录：doctor 报「Found 2 agent directories on disk without a matching agents.entries entry」→ 可作清理项一并处理。
4. 桥接版本核对：当前运行的 2026.9.5 **正是**官方桥接版本。官方原文（https://docs.openclaw.ai/install/updating）：「For installations older than July 2026, upgrade to **`2026.9.5`** first, run its Doctor migrations, and then upgrade to `latest`.」→ 本机已在桥接版本上，可直接升到 latest，无需先装桥接版。
5. 升级前建议执行 `openclaw backup create` 备份；重启统一走 `bash ~/.scripts/safe-gateway-restart.sh`（该脚本存在且本机 LaunchAgent label 实测为 `ai.openclaw.gateway-auto`，与注册名一致，可安全使用）。
