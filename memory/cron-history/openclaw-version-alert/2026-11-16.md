五、安全事件：本机 Node 根证书库实证
--------------------------------------------------------
实测命令（Node v26.7.0）：
  node -e "const tls=require('tls'),{X509Certificate}=require('crypto');const n=tls.rootCertificates.map(p=>{try{return new X509Certificate(p).subject.replace(/\n/g,' ')}catch(e){return ''}});..."
结果：
  精确匹配 CN=emSign ECC Root CA - G3 → 1 张
  eSign/eMudhra 家族合计 → 4 张（emSign Root CA - G1、emSign ECC Root CA - G3、emSign Root CA - C1、emSign ECC Root CA - C3）
  另含 COMODO 家族 2 张（COMODO ECC Certification Authority、COMODO RSA Certification Authority）
  ⇒ 匹配口径：精确 CN 命中 1 张，eSign/eMudhra 家族共 4 张，连同 COMODO 共 6 张。
版本差距：官方 Node 修复版本为 22.23.4 / 24.22.1 / 26.12.1；本机 Node 为 26.7.0，**低于 26.12.1**。
⇒ 结论：本机 Node 仍信任上述受影响根链（emSign ECC Root CA - G3 仍在库中），属于受影响区间；此结论由本机实测得出，不是由「某版本提高了 engines」推断。

1) Session SQLite 未迁移 —— doctor 原文：
   "Legacy entries: 1377; SQLite entries: 1371."
   "Found 1354 session SQLite issue(s). Inspect with \"openclaw doctor --session-sqlite dry-run --session-sqlite-all-agents\"."
   → **不要带着未迁移会话直接升级**。需先停 Gateway，再执行：
     openclaw doctor --session-sqlite recover --session-sqlite-all-agents
   （该数字为 09:11 实测值；迁移会持续推进，数字会漂移，复跑可能不同。）

2) 无 command owner —— doctor 原文："No command owner is configured."
   → commands.ownerAllowFrom 未设置，/update、重启 Gateway、改配置无授权主体。升级前建议先配置可信操作者账号。

3) 孤儿 agent 目录 —— doctor 原文："Found 2 agent directories on disk without a matching agents.entries entry"
   → 可作为清理项（恢复缺失的 agents.entries 条目或移除陈旧目录）。

4) 桥接版本 —— 官方 https://docs.openclaw.ai/install/updating 原文："For installations older than July 2026, upgrade to `2026.9.5` first, run its Doctor migrations, and then upgrade to `latest`."

5) 安全地板 vs 准入门槛（不互斥）：
   engines 满足 = 能装能跑；Node 安全发布地板（26.12.1）只是**建议**，OpenClaw 不会因此拒绝安装 2026.11.3。本机 Node 26.7.0 装 2026.11.3 不受该地板阻断，但 eMudhra 根证书问题需通过升级 Node 到 26.12.1+ 才彻底消除。

   ~/.scripts/safe-gateway-restart.sh 存在且可执行（7108B）。实测其内容：LaunchAgent label = `ai.openclaw.gateway-auto`（本机真实注册），PID 探测顺序 launchctl → ps → pgrep，pgrep 模式为 "openclaw-gateway"（不再误命中 project-tracker 的 Python 进程）。→ 升级后可用该脚本重启，避免直接 `openclaw gateway restart` 立即 SIGTERM 丢消息。
