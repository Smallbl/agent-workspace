1. 国家发改委：加快人工智能立法，首推"监管沙盒"
国家发改委创新和高技术发展司副司长王若蒙在11月3日发布会上表示，将加快AI立法，建立覆盖数据、算力、算法全链条、贯穿模型全生命周期的安全标准与伦理规范，同时通过过渡期和分行业监管沙盒为创新"松绑"。他同时透露政府将监测AI对就业影响并为受冲击劳动者提供社会保障。相关数据显示，过去一年中国开源大模型全球下载份额升至17.1%，首次超越美国的15.8%。

2. OpenAI 重写模型准则：第一条是"忠于人类"
OpenAI 11月2日更新 Model Spec，列出5条核心价值观，首条即"忠于人类意图"——强调不是字面服从指令，而要结合上下文、记忆和长远意图判断用户真正想做什么。其余为"减少伤害、诚实透明、促进人的自主性、关怀"，并新增强制可纠正性、禁止自我保存与算力积累、越权行动立即停止等硬性红线。准则中的称谓也从"the assistant"改为"GPT"。

4. DeepSeek 开源 Agent 底座架构

5. 腾讯混元发布 Hyra 2.0：科研范式从"刷题解题"走向"造工具"
11月2日腾讯混元发布 AI 科研系统 Hyra 2.0，研发重点从直接用 AI 攻克科学难题，转向让通用 Agent 参与科学模型、研究工作流与软件工具的研发升级，使一次研发成果可在后续研究中反复复用。官方称目标是形成"智能复利"。
