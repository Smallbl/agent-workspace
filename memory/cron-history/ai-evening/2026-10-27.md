2. OpenAI 宣布三项重大科学突破，触及千禧年难题
OpenAI 称其模型在数学、计算机科学与物理学取得三项独立突破：证明局部光滑猜想并解决局部光滑猜想与挂谷猜想；推翻长期被接受的指数时间假设（意味着可能存在更快的算法）；提出量子色动力学及杨–米尔斯理论的严格数学存在性证明，属克雷数学研究所千禧年大奖难题的一部分。数学与计算机科学成果已通过 Lean 形式化验证并公开证明材料，物理成果由诺奖得主大卫·格罗斯等专家审查，仍待学界独立确认。

3. 国办发文定调：减缓AI就业替代，构建"就业友好型"发展方式
国务院办公厅印发《关于适应人工智能技术发展助力构建就业友好型发展方式的意见》（国办发〔2026〕29号），从6方面部署18项任务，核心是"有效减缓人工智能应用就业替代影响"。亮点包括：稳慎把握AI在劳动密集型行业的应用范围、力度与节奏；鼓励企业建立"失业缓冲期制度"、大规模应用前提前告知受影响劳动者；对可能造成较大就业冲击的应用场景项目同步开展就业风险评估；加快开发人工智能训练师等新职业新工种。

4. 腾讯混元开源同声传译模型 Hy-SimulMT，3秒延迟超人类译员
Hy-SimulMT 支持中英语音到语音实时翻译，边听边译、实时输出译文与语音，并支持实时音色克隆还原说话人语气。实测响应时间约3秒，快于人类专业译员平均的4-5秒；在长音频评测集 RealSI 上以最低延迟达到开源模型最佳水平，超过多数商用同传API，翻译质量经6名CATTI持证专家对比达人类专家水平。已上架腾讯 Hy 翻译 App 免费体验，并开放 GitHub 推理与微调代码。
