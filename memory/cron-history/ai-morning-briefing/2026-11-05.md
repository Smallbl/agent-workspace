1. Anthropic 开源 FlashProve：给大模型办一张「防伪身份证」
Anthropic 开源了名为 FlashProve 的可证明推理系统，基于零知识证明（zkSNARK），让服务商能在不公开模型权重的前提下，用密码学证明某个回答确实来自指定模型。已在 4000 亿参数的 Llama 4 Maverick 上验证，单张 H100 每秒可生成约 110 Token 的证明，24 线程 CPU 约 17 秒即可验证一份。局限是证明生成的 GPU 时间比普通推理高 72–94 倍，目前仍是研究原型。

2. 腾讯混元正式发布 Hy4，跻身全球最强开源模型第一梯队
11 月 4 日腾讯混元推出新一代大模型 Hy4，总参数 770B、激活 49B、上下文 1M tokens。相比 8 月的 Hy4 preview，Hy4 首次加入视觉多模态理解与 Computer Use（电脑操作）能力，并针对 Blender、CAD 等专业软件做专项训练。213 位金融专家、579 项真实任务的盲测中综合得分位列开源模型第一，幻觉率从 12.95% 降至 7.2%。权重将于近期开源，定价维持每百万 Token 输入 6 元、输出 18 元不变。

3. 美团发布 LongCat-2.5：1.6 万亿参数，全程国产算力训练
11 月 2 日美团发布面向长程智能体任务的原生多模态大模型 LongCat-2.5，总参数 1.6 万亿、每 Token 激活约 480 亿，训练全程使用国产算力，是目前国产算力上完成的最大训练任务。推理侧采用 W4A4 方案，相比 W8A8 基线吞吐提升约四成；中训练最长序列达 1M token，单卡训练吞吐量较 DDP 基线提升 86%。多项基准成绩介于 Claude Opus 4.8 与 Opus 5 之间，部分项目超过 Opus 5。

5. DeepSeek 开源 Super-agent：Agent 不下班、不用你 @，任务时间砍半
DeepSeek Harness 团队发布《Super-agent 设计探索》并开源原型 dsh-superagent-prototype，把 Agent 从一次性会话做成常驻连续实体。架构上采用 Router（全局调度）+ Worker（隔离执行）双层设计，引入调度、存算分离、看门狗等操作系统级概念，支持在无人 @ 的情况下主动识别群聊中的缺陷并在后台复现修复。实测 95% 任务在 15.7 分钟内完成，对比传统单会话+子智能体方案的 29.5 分钟缩短近半。
**原文链接：https://developer.cloud.tencent.com/article/2774420

6. 普林斯顿 AI Lab 出「空间智能」考卷：人类 83.3%，大模型最高 39.7%
普林斯顿 AI Lab 提出 Same Space or Not（SSoN）基准，只给四张静态室内图像，让模型找出违背同一场景的那一张并解释原因。完整 1000 题上人类准确率 83.3%，六个受测 VLM 中 GPT-6 Astra Pro 以 39.7% 领先，其余五个全部低于四选一 25% 的随机基线。原因是基准特意构造了「看着像变了、空间上却正确」的强干扰视图，暴露了模型从「识别差异」到「理解空间」之间的缺口。
