# 【AI早报】📅 2026-07-24

## 今日要闻

**1. Kimi K3 发布刷新开源大模型纪录，中国AI首次登顶全球性能榜首**
月之暗面（Moonshot AI）在WAIC前夕发布新一代旗舰模型Kimi K3，以2.8万亿总参数成为全球参数最大的开源模型，在Frontier Code Arena前端代码榜单以1679分超越Claude Frontier 5登顶第一。苹果首任AI总监、杨植麟在美读博导师鲁斯·萨拉霍丁诺夫第一时间发文祝贺。被部分华尔街机构称为"DeepSeek 2.0时刻"。
来源：新浪AI热点（综合36氪、机器之心等）

**2. 美国威胁因"模型蒸馏"制裁中国AI，中美9月将开展AI谈判**
美国财政部长贝森特表态，特朗普政府准备调查中国AI大模型是否通过"蒸馏"借鉴美国模型。Anthropic已向美国国会投诉某大厂大规模蒸馏，中美计划9月开展AI谈判，贝森特代表美方。Kimi K3等中国开源模型快速追赶，美方担忧领先优势不保。
来源：新浪AI热点（援引CNBC、Reuters）

**3. AI算力激增：美国数据中心2035年用电量或翻四倍，消耗全美五分之一电力**
彭博新能源财经报告显示，受AI计算需求推动，预计2035年美国数据中心用电量增至目前四倍，届时消耗美国五分之一电力。全球数据中心容量将扩至接近200吉瓦。国际能源署预测2030年全球数据中心电力需求增长一倍以上至945太瓦时。
来源：中国科技网（援引纽约时报）
