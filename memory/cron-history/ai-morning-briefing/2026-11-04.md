三、DeepSeek 开源 Super-agent 架构：把计算机系统经典设计搬进 Agent
10月31日晚 DeepSeek Harness 团队公布自主 Agent 探索"Super-agent（超级智能体）"的底层架构并开源 MIT 原型。核心是双层架构（Router 分派 + Worker 执行）、事件驱动（群聊/CI/邮件等 Trigger 两级过滤后自主推进）、异步多信道交互、存算分离（计算与状态上云、执行环境留本地，支持 BYOM）以及外部 Watchdog 自愈。实验显示 Super-agent 的 p50/p95 完成时间为 12.4/15.7 分钟，明显优于单 Session+Subagent 方案的 29.5 分钟。
