**2. Anthropic 30亿美元收购 API「修路工」Stainless，剑指连接层标准制定权**

AI安全公司 Anthropic 宣布以3亿美元收购 Stainless，后者客户包括 OpenAI、Google、Cloudflare、Replicate 和 Runway 等头部玩家。Stainless 的核心业务是将 API 规范自动转换为多语言 SDK，并提供 MCP（Model Context Protocol）服务器平台。Anthropic 借此将 MCP 协议的工程实现标准握在自己手里，意在控制 AI Agent 连接外部系统的"连接标准制定权"，从单纯的"卷模型"转向"卷生态"。
